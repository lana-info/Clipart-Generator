# Настройка RunPod для экспериментальной GPU-очистки

Приложение уже содержит клиент RunPod Serverless. Пользователю нужно только:

1. Создать аккаунт на [RunPod](https://www.runpod.io/).
2. Открыть [Billing](https://console.runpod.io/user/billing) и пополнить баланс (там же проверяется текущий остаток).
3. Создать Serverless Endpoint с контейнером/воркером обработки из проекта.
4. Скопировать Endpoint ID и создать API-ключ в [настройках пользователя](https://www.runpod.io/console/user/settings).
5. Открыть в приложении «Настройки API», ввести RunPod API Key и Endpoint ID и сохранить.

После этого запуск экспериментальной GPU-обработки выполняется обычной кнопкой обработки. Отдельный чекбокс согласия в интерфейсе не используется: нажатие кнопки является действием пользователя. Изображения передаются только при выбранном облачном режиме и активном запуске.

Документация RunPod Serverless: [overview](https://docs.runpod.io/serverless/overview). Цены: [RunPod pricing](https://www.runpod.io/pricing).

Приложение открывает страницу Billing по ссылке, но не показывает баланс внутри окна: официальный API RunPod предоставляет историю биллинга, а не стабильный endpoint текущего остатка.

## Важно для Endpoint

Endpoint должен принимать JSON `input` и возвращать результат в формате, который ожидает ваш worker. Само приложение проверяет API-ключ, Endpoint ID, таймаут и ограничивает размер ответа; оно не создаёт Endpoint автоматически и не выполняет запрос без нажатия кнопки.

# Импорт: Digital Creator Club

Источник: пользовательский архив `digital-creator-club-archive-2026-09-08.zip`.
Дата импорта: 2026-09-08.

## Что сохранено

- `original-archive.zip` — исходный архив без изменений.
- `source/` — полный предоставленный исходный код Next.js-прототипа и двух WordPress-плагинов.
- `screenshots/teddy_bear_4.png` — единственный доступный визуальный материал.
- `README.md`, `MANIFEST.txt`, `dialog.txt`, `CHECKSUMS.sha256` — исходные сопроводительные материалы.

Внутренние SHA-256 сверены успешно. Файл хэшей был создан в Windows: для проверки на Linux во временной копии заменены обратные слеши в путях и CRLF. Содержимое архива не менялось.

## Что полезно для Clipart Generator

1. `source/src/lib/clipart-generator.ts` — ранний детерминированный генератор идей и готовых prompt'ов. В нём есть модель входных данных: тема, шаблон, группы элементов, правила, палитра, соотношение сторон и сохранение референса.
2. `source/src/app/tools/clipart-generator/clipart-generator-tool.tsx` — интерфейс генератора наборов: идеи или prompt'ы, группы, палитра, правила и копирование результата.
3. `source/wordpress/digital-creator-club/` — более широкий WordPress-сервис. Он содержит серверные инструменты для генерации prompt'ов и обработки референсов через настраиваемый OpenRouter API, а также настройки отдельных моделей.
4. `source/PRD.md`, `source/TASKS.md` — планы завершённого Pinterest-планировщика. Их можно использовать как пример структуры продукта, но это не требования текущего приложения.

## Важные границы

- Это не готовая реализация автоматического chroma-key / удаления фона. В архиве нет логики выбора key-цвета, сохранения generation metadata, connected-region removal, matting или QC-пайплайна.
- Код WordPress и Next.js не следует копировать в desktop-приложение напрямую. Полезны его UX-идеи, типы данных и правила построения prompt'ов; интеграцию нужно проектировать отдельно для текущего Python-приложения.
- В `dialog.txt` лежит только короткая служебная переписка. Полной истории исходного чата в архиве нет.
- В `MANIFEST.txt` указаны два недоступных скриншота. Их в архиве действительно нет.
- Поиск не выявил сохранённых значений API-ключей. Есть только поля настроек и код работы с ключом OpenRouter.

## Рекомендованное использование далее

Когда будем проектировать режим «Автоматический Clipart», взять этот импорт как исторический референс для отдельного конструктора prompt'ов: пользователь вводит тему и художественные параметры, а технические правила безопасного непрозрачного фона, chroma-key и валидации добавляет приложение. Не переносить прежнее правило `no background`, поскольку оно противоречит новому chroma-key workflow.

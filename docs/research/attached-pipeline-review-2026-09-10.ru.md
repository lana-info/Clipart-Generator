## Метод и результаты

scripts/compare_attached_chroma.py читает указанный ZIP без установки пакетов,
запускает его пять tests и оба движка на шести существующих goldens.
Trim отключён у кандидата для совпадения координат. Текущий профиль:
opaque_clipart. Метрика: chroma_quality.reference_quality, нормированные
float RGB ошибки композиции на чёрном, partial-alpha p95 (меньше лучше).

| Fixture | Текущий | ZIP | QC ZIP |
| --- | ---: | ---: | --- |
| clean-edge-blue | нет partial samples | нет partial samples | OK |
| soft-edge-red | 0.281892 | 0.791370 | OK |
| thin-lines-green | 0.229846 | 0.879723 | warning |
| openings-blue | 0.269158 | 0.992695 | OK |
| partial-alpha-red | 0.291826 | 0.499423 | OK |
| color-spill-green | 0.174833 | 0.680168 | OK |

Пять авторских tests проходят. Это не доказательство качества: визуальное
сравнение показывает стирание линий и синие залитые отверстия при QC OK.
Soft/partial fixtures включают случаи вне узкого opaque production-профиля;
они проверяют устойчивость и сохранность, не задают желаемую художественную
мягкость края. Текущий движок также имеет заметные ошибки, не объявлен готовым.

Два дополнительных probes: объект у рамки полностью исчезает (0 opaque pixels,
QC false); существующее прозрачное отверстие alpha=0 становится alpha=255.
Причины: label 0 connectedComponents попадает в набор border labels, RGB
conversion теряет исходную alpha, MORPH_CLOSE удаляет тонкий foreground,
изолированные отверстия безусловно считаются предметом. Геометрический feather
не восстанавливает истинную coverage; unmix с неверной alpha усиливает ошибки.
QC проверяет площади, а не сохранность/резкость деталей. В отличие от текста
исследования код требует cv2 и не содержит полного router/FastAPI/retry workflow.

## Решение и уточнение предыдущего обзора

Кандидат не заменяет chroma_key.py. Использовать идеи как гипотезы с эталонами.
Уже существует Worker skip_remover_for_alpha (по умолчанию true): прежний
обзор ошибочно описал отсутствие alpha-маршрута слишком широко. Нужны
capability-driven generation intent и общий QC, а не второй worker/router.
Подбор key сейчас текстовая RU/EN эвристика, не анализ пиксельной палитры.
Receipt содержит происхождение удаления, не generation request.

Добавлен conservative native_alpha.preserve_native_alpha в существующий
Worker reuse: точная coverage/видимый RGB, RGB=0 при alpha=0, пустой файл
отклоняется. Никакой gamma/snap/искусственной резкости. Сохранение alpha
не доказывает отсутствие белой каймы или размытых лепестков.

### Решения после сопоставления с полным направлением проекта

1. Диалог о 50 коллекциях и 80 элементах полезен как пример структуры набора,
   но не фиксирует объём производства или спрос. Сначала небольшой связный
   набор/образец; готовые коллекции не переделывать автоматически. Роли главных
   элементов, акцентов и композиций хранить; повторно использованные элементы
   не выдавать за новые уникальные изображения. Quality Preview и реальные
   размеры оставить в экспортном плане, без обещания perfect edges.
2. Общий конструктор: собственные Holiday-пресеты, условные поля персонажей,
   редактируемая палитра, словарь название → инструкция, пользовательские
   настройки. Праздник и персонаж совместимы, не взаимоисключающие приложения.
   Midjourney исключён по прямому решению владельца, KIE/fal.ai сохраняются.
3. Множественный выбор деталей и комбинации отдельных заданий разделяются.
   Комбинации показывают состав, число и стоимость до запуска. Пресет не
   запускает API и не переключает модель. Готовый prompt можно исправить.
4. Референсы дают выбранные признаки/палитру/героя, а не обязательное копирование
   картинки. Контактный лист сначала требует области/роли; фон и надписи
   скриншота не становятся содержимым клипарта. Макеты не копируются буквально.
5. Алфавиты требуют отдельной проверки символа, отверстий и согласованности;
   Junk Journal требует сохранения фона бумаги. Оба направления отложены.
   Художественная обводка не является шириной AA-маски; prompt буквы нельзя
   соединять с общим no letters. Стиль watercolor/flat 2D не навязывается всем.
6. В Patterns использовать собственный каталог композиций. No cut-off at borders
   не универсальное правило: переходы через край допустимы с продолжением.
   Умение написать seamless не заменяет offset и 3×3/5×5 проверку.
7. Профессиональный опыт является основанием сравнить Nano Banana Pro, а не
   отвергать её без проверки. Победитель по стоимости/качеству пока не выбран.
   Прежняя отклонённая Nano Banana 2 проба не проверяла Nano Banana Pro.
8. В исходных таблицах есть ограничения распространения самого конструктора.
   Для Vibix создаём свои тексты, данные, код и превью; полный импорт исходного
   продукта и утверждение прав на него не входят в эту задачу. Пример лицензии
   на клипарт из TXT также не принят как итоговая лицензия приложения/товара.

### Удаление фона: что продолжаем

Сначала подключить generation intent/выбор поддержанного key к конкретному
изображению, затем пройти имеющиеся PNG через общий review/editor/export.
Сохранение native alpha уже реализовано; автоматический generation selector,
полный общий QC и конечная приёмка края остаются открытыми. Opaque/chroma
основной рабочий кандидат, не гарантия Ready. Белый фон и difference matting
не заменяют его; ZIP-перенос отклонён измерениями выше. После конечного resize
проверять белую/чёрную/цветную подложку, край 1:1, отверстия, тонкие детали,
ширину AA и отсутствие ложной каймы. Сомнения → Review, не платный auto-retry.

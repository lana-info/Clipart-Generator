# ui-polish, шаг «Проверка PNG» (макет v2, 2026-10-27)

Собран из настоящего окна (render_png_check.py): png-check-now.png — как сейчас, png-check-proposed.png — как предлагается.
Правки владельца к v1: нет кнопок «Нужно посмотреть»/«Все», нет текстов «Проверьте края» и инструкций; значки на превью:
зелёный — Ок, оранжевый — брак генерации, фиолетовый — брак вырезания, «!» — нужно посмотреть (без оценки), серый перечёркнутый — исключено;
после «Ок» «!» пропадает. Фон — цветные квадратики внизу, над подвалом (на месте «Параметров экспорта», которые уходят на шаг экспорта).
Кнопка «Редактировать прозрачность» — обычного размера, в одном ряду с «Ок», браками и «Исключить из наборов». Картинка занимает всю освободившуюся площадь;
Ctrl+колесо — масштаб, пробел+мышь или средняя кнопка — перемещение, двойной клик — «по размеру». «К наборам» — внизу слева.

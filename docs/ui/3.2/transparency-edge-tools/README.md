# Окно прозрачности: инструменты краёв — скриншоты до/после

PRD: docs/PRD_TRANSPARENCY_EDGE_TOOLS.ru.md. Каждый пункт — своя папка, в каждом файле слева «до» (develop/3.2
до слияния пункта), справа «после». Фоны: белый, тёмный, клетчатый. Картинка — тестовый цветок с мягким краем ~6 px.
Снимок виджета не содержит системного курсора, поэтому курсор, который поставило окно (перекрестие или стрелка),
дорисован поверх в точке мыши.

Пересъёмка: `capture.py shoot <корень репо> before|after <пункт> <папка>`, затем `capture.py compose`.

## 01-lasso-cursor-esc — пункт 1 (ошибка #transparency-lasso-cursor-20261022)
- `1a-brush-after-lasso-*`: перо → лассо → кисть. До: поверх кольца кисти висит перекрестие лассо. После: только
  кольцо кисти и обычная стрелка, как у кисти без лассо.
- `1b-esc-with-selection-*`: выделение лассо в полноэкранном режиме и одно нажатие Esc. До: окно вышло из
  полноэкранного режима, выделение осталось. После: выделение снято, режим остался; второй Esc выходит из него.

## mockups — макеты пунктов 2–4 (ждут одобрения владельца, код не писался)
Слева текущее окно, справа предложение. Собраны на настоящем окне, изменения только в `render_mockups.py`
(пересъёмка: `render_mockups.py <папка>`, затем `capture.py mockups <папка> 2|34 mockups`).

**Пункт 2, курсор кисти** (`2-cursor-*`, белый/тёмный/клетчатый, жёсткая 16 px и мягкая 40 px, масштаб 200 %).
Сейчас кольцо белое и на белом фоне не видно. Предложение: тёмное кольцо 3 px под светлым 1,5 px, ровно по
диаметру кисти. У мягкой кисти дополнительно тонкое пунктирное кольцо: докуда доходит мягкий край.

**Пункт 3, панель инструментов** (`34-panel-brush|pen|lasso`). Строка «Инструмент»: три кнопки «Кисть», «Перо»,
«Лассо» с подписями. У пера в блоке «Контур» остаются две равные кнопки «Обвести» и «Автоконтур» (широкая кнопка
лассо уходит в общую строку). Остальное в пере без изменений.
Лассо как отдельный инструмент: обводит область на картинке (Shift — добавить, Esc — снять). Если на картинке
есть контур пера, точки внутри области тоже выделяются, поэтому «Упростить» и работа с точками в пере остаются.
Панель лассо: подсказка, строка «Область выделена · точек контура в ней: N», кнопка «Снять выделение».

**Пункт 4, кнопки краёв** (блок «Край»). Сейчас: «Чётче» и «Сгладить». Предложение: «Жёстче», «Мягче», «Сгладить»
и второй ряд «Сузить», «Расширить». «Чётче» убирается: она доводит край до 0/255 («лесенка»), а «Жёстче» делает
то же безопасно (переход 2–3 px). Под кнопками область действия: «Всё изображение» или «Область лассо».
Каждое нажатие — один шаг отмены.

Вопросы владельцу: 1) одобрить три макета или что поправить; 2) лассо = область (+ точки контура в ней);
3) убрать «Чётче», оставить «Сгладить».

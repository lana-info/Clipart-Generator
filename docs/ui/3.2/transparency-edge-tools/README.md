# Окно прозрачности: инструменты краёв — скриншоты до/после

PRD: docs/PRD_TRANSPARENCY_EDGE_TOOLS.ru.md. Каждый пункт — своя папка, в каждом файле слева «до» (develop/3.2
до слияния пункта), справа «после». Фоны: белый, тёмный, клетчатый. Картинка — тестовый цветок с мягким краем ~6 px.
Снимок виджета не содержит системного курсора, поэтому курсор, который поставило окно (перекрестие или стрелка),
дорисован поверх в точке мыши.

Пересъёмка: `capture.py shoot <корень репо> before|after <пункт> <папка>`, затем `capture.py compose`.

## 01-lasso-cursor-esc — пункт 1 (ошибка #transparency-lasso-cursor-20261022)
- `1a-brush-after-lasso-*`: перо → лассо → кисть. До: поверх кольца кисти висит перекрестие лассо. После: только
  кольцо кисти и обычная стрелка, как у кисти без лассо.
- `1b-esc-with-selection-*`: выделение лассо в полноэкранном режиме и одно нажатие Esc. До: окно вышло из
  полноэкранного режима, выделение осталось. После: выделение снято, режим остался; второй Esc выходит из него.

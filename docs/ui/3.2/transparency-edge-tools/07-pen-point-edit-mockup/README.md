# Перо: добавить/удалить точку, группа точек (2026-10-23)

Макет `all-proposed.png` (01–03) утверждён владельцем 2026-10-23. Реальные экраны после реализации — `actual/`
(снимает `../capture.py shoot <repo> after 7 <out>`).

- Ctrl + ЛКМ по линии — угловая точка, Ctrl + ПКМ — точка кривой; форма линии не меняется.
- Ctrl + щелчок по точке или Delete — удалить; в контуре остаётся минимум 3 точки. Ctrl+Z возвращает.
- С Ctrl над контуром курсор «+»/«−» и подсветка места; подпись в панели меняется.
- Лассо или Shift+щелчок выделяют группу; тянете любую выделенную — двигаются все (один шаг отмены);
  стрелки 1 px, Shift — 10 px; Delete удаляет все выделенные.

Отличия от макета: подписи в панели переносятся на вторую строку (узкая колонка); в подписи группы оставлено
«Esc — снять» (поведение Esc уже было утверждено ранее, см. docs/ERRORS.md #transparency-lasso-cursor-20261022).

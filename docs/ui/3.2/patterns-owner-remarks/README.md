# Patterns: замечания владельца П1–П8 — макеты на утверждение (2026-10-23)

Реальная страница Patterns 3.2 (вымышленные рисунки) под шапкой Studio. Слева «СЕЙЧАС», справа «ПРЕДЛАГАЮ».
Скрипт: `python render_mockups.py <repo> <out>`. Код — только после «утверждаю».

- **П1 + П2** `P1-P2-header-and-plaque.png`: плашка «Patterns · Новый набор / Главная Studio / Настройки API /
  Диагностика» убрана (те же кнопки есть в шапке). В шапке «Паттерны» вместо «Автоматический клипарт» — причина
  найдена: `V3ApplicationView._set_application_screen` для любой страницы модуля, кроме шагового окна, пишет
  «Автоматический клипарт».
  Правка владельца 2026-10-23: на шаге 1 оставить только кнопку «Добавить PNG» (в окне выбора можно выделить сразу
  много файлов), кнопку «Добавить папку» убрать — макет обновлён.
- **П3** `P3-P5-P6-settings-live-preview.png`: на шаге 2 справа постоянно виден лист, обновляется сам через ~0,5 с после
  изменения; настройки — в колонке слева с прокруткой («Расстановка» сверху).
- **П5** `P5-settings-not-enough-room.png`: вместо «placed 8 of 27…» — по-русски, сколько поставлено, почему и что
  уменьшить. (27 = запрошенное количество из прежних настроек; в новой подписи берётся текущее значение ползунка.)
- **П6** `P6-settings-background-scrolled.png`: образец фона кликается (выбор любого цвета), подпись «Фон попадёт в
  итоговый файл. «Прозрачный» — только для PNG».
- **П4** `P4-tile-source-texts.png`: для готовой плитки нет ложного «0 из 1 файлов с прозрачным фоном» — вместо него
  «Плитка W × H px. Прозрачный фон для готовой плитки не нужен.» Кнопки «Добавить PNG / Добавить папку» в режиме
  «Из ваших PNG» в коде есть (см. 02 в patterns-module-proposal/actual) — проверю на сборке, при каком шаге они пропадали.
  Правка владельца 2026-10-23: кнопка «Выбрать файл» / «Выбрать другой файл» (а не «плитку»). Размер (в макете
  600 × 600) — только сведения о выбранном файле, не требование; показывается один раз: «Выбран файл … · W × H px.
  Подойдёт файл до 8192 px по стороне; шов проверим на следующем шаге».
- **П7 (правка владельца 2026-10-23: править на шаге 2, не на шаге 3)** `P7-manual-placement-step2.png`: ручная
  расстановка прямо в живом предпросмотре шага 2: «Двигать / Поворот / Размер / Убрать», «Вернуть автоматическую
  расстановку»; рамка с ручками, кружок — поворот; элемент у края появляется и с другой стороны листа. Ручные правки
  сохраняются в проекте, «Пересобрать» (другая случайная расстановка) их не трогает.
- **Шаг 3 — только проверка повтора (правка владельца 2026-10-23)** `P9-step3-repeat-check.png`,
  `P10-fullscreen-repeat.png`: выбор «Показать плиток» 3×3…7×7, «Сетка» вкл/выкл, «На весь экран» (Esc — выйти).
  Подписи понятными словами: стык проверяет программа автоматически; из PNG программа ничего не исправляет (лист
  бесшовный по построению), для готовой плитки — смешивает полосу у краёв. «Добавить лист в набор» → «Сохранить в
  набор» (лист попадает на шаг 4, где делаются ещё варианты и выгружаются все листы); «Пересобрать с другим seed» с
  шага 3 убрана — другая расстановка делается на шаге 2. «Увеличить шов» заменена сеткой и режимом на весь экран.
- **П8** `P8-too-large-png.png`: вместо «Нужен PNG не больше 8192 px» — фактический размер, какое ограничение
  сработало, и кнопка «Добавить уменьшенную копию» (исходник не меняется).

## Правки владельца 2026-10-23 (вторая итерация шагов 2 и 3)
- Шаг 2: без кнопок «Двигать / Поворот / Размер / Убрать» — элемент выделяется мышью: тянуть — двигать, углы рамки —
  размер, кружок — поворот, значок корзины рядом с рамкой или Delete — удалить. Кнопка «Сбросить правки» (подсказка:
  вернуть автоматическую расстановку). Заголовок карточки — «Предпросмотр».

  картинке.

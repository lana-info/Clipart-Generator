# Auto Clipart, экспорт: «Проверка PNG перед экспортом» — макет на утверждение (2026-10-23)

Замечание владельца (снимок 3.2.39): кнопка «Создать ZIP-наборы» повторяется дважды; непонятно, что делать на экране;
справа «Готово / Проблем не найдено», хотя один файл нужно посмотреть.

Что это за экран: перед сборкой ZIP программа сама проверяет края и прозрачность каждого PNG (`studio_alpha_qc`),
файлы не меняет. Справа — результат для выбранного в списке файла; по умолчанию выбирался первый файл (обычно
«Готово»), а проблемный терялся в длинном списке.

Предложение `export-png-check.png` (`render.py <repo> <out>`):
- заголовок «Проверка PNG перед экспортом», без поясняющего абзаца (правка владельца: минимум подписей);
- строка «Нужно посмотреть: N из M. Остальные — готовы.»;
- переключатель «Нужно посмотреть (N) / Все (M)», по умолчанию — только проблемные, первый выбран сразу;
- справа — картинка выбранного PNG на клетчатом фоне, проблема и что сделать; кнопки «Открыть в проверке
  прозрачности» и «Исключить из наборов»;
- «Создать ZIP-наборы» одна — внизу окна; кнопка внутри экрана убрана; «← К наборам».

Статус: утверждено владельцем 2026-10-24 («утверждаем макеты так как ты предложишь»); реализовано в `studio_set_export_ui.py`,
реальный экран — `actual/export-png-check-actual-1120x780.png` (`capture_actual.py`), совпадает с макетом.

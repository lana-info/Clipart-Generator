# Автоматический Clipart: единая страница экспорта

Статус: макеты одобрены владельцем в чате 2026-09-29 и реализованы. Исходный
экран шага 8 показан в сообщении пользователя 2026-09-28: только дерево
наборов и PNG; состав доступен лишь после отдельной кнопки «Экспортировать».
Нынешний `SetExportDialog` уже умеет менять галочки состава и показывать PNG
по наведению в ручной таблице, но не умеет создавать, переименовывать и
удалять наборы.

## Предложение

- `proposed-export-summary.png`: шаг 8 сразу показывает числа готовых PNG и
  наборов, карточки наборов с миниатюрами и кнопками «Изменить», «Удалить»,
  «Новый набор». «Создать ZIP-наборы» запускает только финальный экспорт.
- `proposed-export-hover.png`: наведение на название PNG открывает крупное
  превью рядом с курсором. PNG содержатся только в памяти/на диске пользователя,
  в документации используются нарисованные фиктивные изображения.
- `proposed-export-edit.png`: таблица состава на том же шаге. Галочки включают
  один PNG в один или несколько наборов; изменения сохраняются отдельно от
  создания ZIP. Пока состав меняется, экспорт недоступен.
- `proposed-export-create.png`: создание набора с названием и выбором хотя бы
  одного готового PNG; генерация заново не запускается.
- `proposed-export-delete.png`: подтверждение удаления только набора. PNG и
  существующие результаты не удаляются. Если наборов не осталось, кнопка
  экспорта становится недоступной до создания нового.

Один редактор встроен в шаг 8, поэтому двух разных списков наборов больше нет;
сохранение распределения остаётся в проекте и действует после перезапуска.
Финальные локальные снимки с фиктивными PNG:
`actual-export-summary-1120x780.png`, `actual-export-create-1120x780.png`,
`actual-export-edit-1120x780.png`. На них проверены список, миниатюры,
галочки, доступность действий и размещение при целевых 1120×780. Снимок
сделан в Qt offscreen с упрощённой боковой панелью; точный системный вид
Windows остаётся для нативной проверки.

Название задаётся при создании набора и меняется кнопкой «Переименовать».
Экспорт использует безопасное имя файла вида
`001_зимние-персонажи.zip`; номер сохраняет порядок при нескольких наборах.
Подтверждение удаления касается только набора, PNG на диске не удаляются.

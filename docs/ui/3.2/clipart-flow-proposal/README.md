# Clipart: поток из шести коротких шагов

Статус: УСТАРЕЛ. В нём шесть экранов, тогда как владелец утвердил текстовую
структуру из восьми экранов в PRD §6 «Состав восьми экранов Clipart». Это не
рабочий UI и не разрешение на его реализацию.

Макет заменяет одиночный экран проверки как основной путь пользователя, не
отменяя его детали. Пользователь уже открыл отдельный модуль Clipart из
каталога Studio. Patterns и Junk Journal здесь отсутствуют.

1. [Идея и рецепт](01-brief-1120x780.png): основная тема, один опциональный
   контекст (широкий сезон либо конкретный праздник) и пять количеств ролей.
   Нет prompt'ов, настроек провайдера или запуска.
2. [Визуальное направление](02-style-1120x780.png): техника, настроение,
   палитра и референсы. Референс получает роли: техника/стиль, палитра,
   настроение, персонаж/предмет и композиция; это не только источник цветов.
3. [Варианты состава](03-plans-1120x780.png): три редактируемых баланса из
   одного рецепта. Пользователь выбирает один, не создавая изображения.
4. [Проверка и запуск](04-launch-1120x780.png): раскрытый план, prompt и
   подтверждённая цена. Единственное необратимое действие: запуск генерации.
5. [Проверка результата](05-review-1120x780.png): Ready отделены от Review;
   ручной редактор открывается только для проблемного результата.
6. [Экспорт](06-export-1120x780.png): каждый набор имеет собственный ZIP с
   Ready PNG, обзорным листом и manifest. Review не входят по умолчанию.

В верхней части каждого экрана остаются название модуля, текущий проект и
простой индикатор из шести шагов. Главная кнопка одна; второстепенные действия
сознательно понижены. Экраны не добавляют переключатель типа товара и не
обещают фактические цены или завершённый QC.

Рендер: `/tmp/vibix32-venv/bin/python docs/ui/3.2/clipart-flow-proposal/render_mockups.py`.
Скрипт использует только локальные PyQt-примитивы, временный `LOCALAPPDATA` и
демо-данные. Он не меняет рабочий интерфейс, проект, результаты или API-ключи.
После утверждения потребуется отдельный план реализации и проверка реального
интерфейса на всех состояниях до подключения платной генерации.

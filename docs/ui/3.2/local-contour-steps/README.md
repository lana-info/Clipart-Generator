# Локальные контурные инструменты

Обновлённые состояния согласованы владельцем 2026-10-01: «Да, реализовать».
Ранее согласованы расположение и выделение маджентой с контрастной обводкой.
Макеты1120×780 используют только synthetic content; это визуальный образец,
а не проверенный пользовательский сценарий.

- approved-current.png: исходный интерфейс.
- approved-empty.png: без выделения.
- approved-selected.png: выделение лассо и доступные действия.
- approved-preview.png: До/После и отмена обработки участка.
- approved-limit.png: обе кнопки недоступны при достижении безопасного предела.

Нет выбора силы: каждое нажатие делает фиксированный небольшой шаг.
Доступность «Упростить участок» и «Сгладить участок» вычисляется отдельно
и пересчитывается после изменения выделения, ручной правки и отмены.
Actual Qt screens1120×780: actual-editor-* и actual-appshell-*.png.
Главный агент просмотрел actual-appshell-preview и actual-editor-limit:
расположение и маджента соответствуют согласованному макету. В AppShell
страница816×608, поэтому панель инструментов прокручивается; снимки
scrolled-controls подтверждают доступность Сохранить PNG и К результатам.
Состояние limit получено повторными реальными действиями до обоих no-op,
не нарисовано поверх неработающего интерфейса. Windows не проверен.

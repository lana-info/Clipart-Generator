# Модуль Clipart: проверка и запуск

Статус: НОВЫЙ МАКЕТ, ожидает утверждения. Заменяет отклонённый смешанный
экран [result-kind-proposal](../result-kind-proposal/README.md).

Пользователь уже открыл модуль Clipart из каталога Studio. Здесь только
клипарты: нет плиток, страниц журнала и selector типа товара. Patterns и
Junk Journal имеют собственные интерфейсы и не являются вкладками этого экрана.
Технические библиотеки и палитры могут переиспользоваться внутри модулей.

Слева набор клипартов и состояние промптов (не статус качества изображения).
Выбор строки показывает справа палитру, chroma-цвет и маршрут этого клипарта.
«Изменить в стиле» возвращает к палитре; «Изменить промпт» открывает редактор.
Модель задаётся раньше в настройках генерации Clipart. Отдельный фон может
подбираться для каждого клипарта, но модель/тариф без решения пользователя
не меняются. Уже существующая alpha проверяется вместо повторного вырезания.

«Каталог Studio» возвращает в оболочку с сохранением проекта. Новое назначение
продукта выбирается открытием другого модуля, не сменой типа строки. Передача
готового PNG в Patterns будет отдельным необязательным действием после экспорта.

Для сравнения доступен [снимок существующей Qt-страницы](../result-kind-proposal/current-review-1120x780.png).
Он снят с другими тестовыми настройками, не является прайс-листом. Новый
макет использует прежнюю тёмную палитру/размеры, но убирает смешение модулей.
Все новые цены и данные демонстрационные. Шаги показаны для генерации и
удаления фона без включённого upscale; реальные дополнительные операции должны
отображаться по фактическим настройкам, не скрываться за этими тремя строками.
Возможность палитры на макете не доказывает готовое извлечение цветов из PNG.

## Проверка и следующий шаг

Рендер: `/tmp/vibix32-venv/bin/python docs/ui/3.2/clipart-review-proposal/render_mockups.py`.
Используются только графические примитивы прежнего mockup-скрипта, не его
отклонённая логика или экран. Временный LOCALAPPDATA, без API и credentials.
Макет не меняет рабочий UI и не проверяет интерактивное поведение кнопок.
После утверждения реализовать только экран Clipart и module-specific preflight,
затем сравнить реальный UI на 1120×780 с утверждёнными состояниями. Макеты
самого конструктора Holiday/персонажей, Patterns и Junk Journal утверждаются
отдельно. Работы над ними не считаются разрешёнными утверждением этого экрана.

# Auto Clipart: пометки, заметки, версии и пересоздание — макеты на согласование

Статус: НА СОГЛАСОВАНИИ у владельца (2026-10-22, версия 1). Это не рабочий UI и не разрешение
его реализовать (AGENTS.md, visual approval gate). План задачи: TASKS.md, раздел
«Auto Clipart: пометки, заметки, версии и пересоздание картинок».
Окно проверки прозрачности в макетах — настоящий `ClipartTransparencyEditorPage` на условных
картинках; новые элементы добавлены только в скрипте. Платных запросов нет.
Пересоздать: `python docs/ui/3.2/autoclipart-image-marks/render_mockups.py`.

Что меняется: у каждой картинки появляются метка (Ок / Брак генерации / Брак вырезания / Удалить),
заметка и история версий. Что не меняется: инструменты редактора (масштаб, край, кисть, контур),
шаги мастера, экспорт для картинок с меткой «Ок». Действие пользователя: при проверке отметить
плохие картинки и одной кнопкой пересоздать их, не теряя прежних вариантов.

Правила, показанные на макетах:
- Платная генерация запускается только кнопкой «Пересоздать помеченные» на странице результатов,
  всегда с ценой и подтверждением. В окне проверки — только метка, заметка и промпт.
- Брак вырезания можно исправить сразу в окне проверки (бесплатно, с предпросмотром); если не
  исправлен, «Пересоздать помеченные» вырежет заново бережным режимом.
- Прежняя картинка при любом пересоздании становится версией; её можно вернуть.
- «Удалить» не стирает файл; стирает только «Очистить корзину» с подтверждением.
- Набор после удаления становится меньше; догенерации недостающих в этой задаче нет.

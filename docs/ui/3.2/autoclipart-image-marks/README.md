`codex/autoclipart-image-marks-20261022`. Сравнение с реальными экранами — в конце файла. План задачи: TASKS.md, раздел
«Auto Clipart: пометки, заметки, версии и пересоздание картинок».
Окно проверки прозрачности в макетах — настоящий `ClipartTransparencyEditorPage` на условных
картинках; новые элементы добавлены только в скрипте. Платных запросов нет.
Пересоздать: `python docs/ui/3.2/autoclipart-image-marks/render_mockups.py`.

Что меняется: у каждой картинки появляются метка (Ок / Брак генерации / Брак вырезания / Удалить),
заметка и история версий. Что не меняется: инструменты редактора (масштаб, край, кисть, контур),
шаги мастера, экспорт для картинок с меткой «Ок». Действие пользователя: при проверке отметить
плохие картинки и одной кнопкой пересоздать их, не теряя прежних вариантов.

Правила, показанные на макетах:
- Платная генерация запускается только кнопкой «Пересоздать помеченные» на странице результатов,
  всегда с ценой и подтверждением. В окне проверки — только метка, заметка и промпт.
- Брак вырезания можно исправить сразу в окне проверки (бесплатно, с предпросмотром); если не
  исправлен, «Пересоздать помеченные» вырежет заново бережным режимом.
- Прежняя картинка при любом пересоздании становится версией; её можно вернуть.
- «Удалить» не стирает файл; стирает только «Очистить корзину» с подтверждением.
- Набор после удаления становится меньше; догенерации недостающих в этой задаче нет.

## Реализация и сравнение с макетами (2026-10-22)

Реальные экраны (настоящие виджеты, условные картинки, без запуска генерации): [`actual/`](actual/).
Пересоздать: `python docs/ui/3.2/autoclipart-image-marks/capture_actual.py`.
Окно проверки (01, 02, 04–07) совпадает с макетом. Отличия:

- Страница результатов (09): метки, заметки, фильтр и легенда — как в макете; кнопки
  «Пересоздать помеченные (N)» и «Корзина (N)» стоят отдельной строкой над прежними кнопками
  результатов, а не в одном ряду с ними. Над кнопками — строка «Помечено: …».
- Подтверждение пересоздания (10): при браке генерации показывается прежнее окно оплаты (цена,
  модель, референсы) с добавленными строками про брак вырезания. Если помечен только брак
  вырезания — короткий вопрос «Вырезать заново: N?», без цены (бесплатно); при платном апскейле
  сказано, что стоимость не рассчитана. Вырезание запускается после завершения генерации.
- Корзина (11) — стандартное окно предупреждения с кнопкой «Стереть файлов: N».
- В окне версий (08) показывается «Прежний промпт», только если промпт меняли; промпт хранится лишь
  в этом случае (файл проекта ограничен 2 МБ). Не более 10 версий на картинку.
- Новый вариант после пересоздания встаёт на место прежнего файла с тем же именем (прежний — в
  versions). Раньше перегенерация оставляла старый файл и создавала «…_ready_2.png».

# Окно прозрачности: панели «как в Photoshop» — макет на утверждение (2026-10-23)

Пожелание владельца: «Файлы» и «Инструменты работы с изображением» — перетаскиваемые, с изменяемым размером, можно
убрать, свернуть, открепить. Макет собран из настоящих виджетов окна прозрачности (`render.py <repo> <out>`).

- `01-default-docked-right.png` — по умолчанию как сейчас: обе панели справа. У каждой — заголовок с «⋮⋮» (тянуть),
  «▾» свернуть, «⧉» открепить окном, «✕» убрать. Граница между панелями и картинкой тянется мышью.
- `02-files-left-tools-wide.png` — «Файлы» перетащены к левому краю, «Инструменты» расширены.
- `03-files-hidden-tools-floating.png` — «Файлы» убраны, «Инструменты» отдельным окном над картинкой; меню «Панели ▾»
  возвращает убранные панели; «Сбросить расположение» (как по умолчанию) — только пункт этого меню, отдельной кнопки нет
  (правка владельца 2026-10-23).
- **Масштаб на панели рисунка (идея владельца 2026-10-23)** `04-zoom-on-picture.png`, `04b-zoom-menu-open.png`:
  блок «Масштаб» уходит с панели «Инструменты»; внизу слева на картинке — «− | 100 % ▾ | + | По размеру» (список: По
  размеру, 50–300 %, как сейчас), подсказка «Ctrl + колесо». Масштаб доступен, даже если панель инструментов свёрнута
  или убрана; на панели освобождается место.
- Расположение запоминается и восстанавливается при следующем открытии окна.
- Отличия, которые уберу при реализации: двойной заголовок «Файлы» внутри панели; в макетах 02/03 окно шире 1120 px —
  в реализации минимальная ширина панелей будет меньше, чтобы всё помещалось в 1120 × 780.
- Затрагивает ядро (`v3_transparency_preview.py`) — нужна новая сборка Studio.

## Реализовано 2026-10-23 (ветка `codex/ui-transparency-panels-20261023`)
Реальные экраны: `actual/` (`capture_actual.py <repo> <out>`). Отличия от макета: в режиме «По размеру» список
масштаба показывает фактический процент (например «89 % ▾»), чтобы не повторять кнопку «По размеру»; подсказки у
кнопок — 1–2 слова (правило проекта); расположение панелей хранится в QSettings («Vibix / transparency-panels»).

Все изображения используют только synthetic content.

«Белый фон · чёткий контур» добавлен в существующий список «Метод»,
без регулятора силы или новых ползунков. Пояснение уточнено: чёткий контур
без мягких теней, локальная обработка. Белые детали зависят от сегментации
модели, поэтому интерфейс не обещает сохранить любой белый объект.

При выборе доступного метода «Далее» включается; прямой go_next() защищён
валидацией. Cache readiness проверяется без import модели, session или сети.

Root сравнил actual available/unavailable с approved layout; первоначальное
несоответствие enabled Next в unavailable исправлено. Модель используется
только уже скачанная, до inference проверяется её MD5. Реальный runtime CPU
проверен отдельно на двух private source PNG; они не добавлены в Git.

# Чёткость края с предпросмотром

Владелец одобрил показанный макет2026-10-02: одна кнопка под масштабом,
До/После, Отмена/Применить, без настройки силы. Approved и actual используют
только синтетическую чашку, не пользовательские изображения. Цель1120×780,
Qt offscreen Linux; Windows visual acceptance ещё не проводилась.

Кнопка предлагает контраст alpha×2, не меняя RGB. До применения mask/history
не меняются; нельзя сохранить только просматриваемое предложение. Можно
переключать фон и масштаб, отменить preview или применить After одним шагом
Undo, даже при показе До. Повтор после применения даёт отдельный шаг; пустой
редактор и фактический предел отключают кнопку. Во время preview инструменты
маски/контура выключены; нижние фон/сохранение доступны прокруткой. Отмена
не отменяет ранее применённые правки. Смена файла или уход закрывают preview.

Это явная доводка, не автоматическое удаление фона и не коррекция оттенка.
Очень тонкие детали и намеренная полупрозрачность могут измениться: сначала
проверьте изображение. Цветная кайма остаётся отдельной нерешённой задачей.
Ползунок предложен для дальнейшего обсуждения, но не согласован/не добавлен.

`approved/current.png` показывает предыдущее состояние, `approved/ready.png`
новую кнопку. Состояния Before/After, empty и limit сохранены в обеих папках;
`actual/preview-scroll-bottom.png` подтверждает доступ к нижним кнопкам.
Маска и UI-потоки проверены 57 target tests и 9 независимыми Qt проверками.
Общий безопасный прогон: 2494 tests + 281 subtests PASS, 57 skipped/21 deselected.
После него закреплены и проверены ещё 2 регрессии истории; production source не менялся.

# Patterns: макеты на согласование (5 шагов, 10 состояний)

Статус: НА СОГЛАСОВАНИИ у владельца (2026-10-22, версия 2 после замечаний:
шаги слева, кнопки «Назад» / «Далее», выбор папки кнопкой; оболочка повторяет
модули Auto Clipart и «Обработка изображений»). Это не рабочий UI и не разрешение
его реализовать. Создан по правилам AGENTS.md (visual approval gate), в стиле
существующих макетов Clipart. Картинки построены локальным движком
(`studio_patterns*`) на условных рисунках; платных запросов нет.
Пересоздать: `python docs/ui/3.2/patterns-module-proposal/render_mockups.py`.

Что меняется: добавляется отдельный модуль Patterns (`module_id = patterns`).
Что не меняется: Clipart, его экраны и данные. Действие пользователя: получить
бесшовные листы и выгрузить их файлами для продажи.

Условная видимость: режим «из PNG» показывает раскладки, расстановку и
закрепление; режим «из готовой плитки» скрывает расстановку и блокирует
Half-drop/Brick. Review не входит в экспорт по умолчанию. Перекраски по палитре и
передачи из Clipart в v1 нет (решение владельца).

## Реализация (этап 3) и сравнение с макетами

Реальные экраны (те же состояния, 1120 × 780, демо-данные):
[`actual/`](actual/). Пересоздать: `python docs/ui/3.2/patterns-module-proposal/capture_actual.py`.
Оболочка (карточка заголовка, «Шаги» слева, «Назад» / «Далее») совпадает с макетом v2.
Отличия, найденные при реализации (нужно подтверждение владельца):

- В заголовке название набора («Patterns · Новый набор»), а не фиксированное «Весенний сад».
- «Размер элементов» показывается как «12 % листа» (доля стороны листа), а не «75–125 %».
- «Закрепить» закрепляет все текущие элементы листа (повторное нажатие снимает), «Пересобрать»
  берёт новый seed и расставляет незакреплённые. Выбор отдельных элементов мышью не делался.
- Режим «из готовой плитки»: второй кнопки «Пересобрать с другим seed» нет, набор из одного листа;
  «Оставить как есть (Review)» добавляет лист как Review и он входит в экспорт.
- Листы Review, созданные автоматически на шаге «Набор», в экспорт не входят; лист Review, который
  пользователь добавил сам, входит.
- Состояния «Fail» в режиме «из PNG» не бывает (шов бесшовен по построению), поэтому кнопка
  «Сделать бесшовной» там не показывается.

# Предложение интерфейса: редактор контура

Утверждено владельцем 2026-09-08: «да, продолжай разработку» в ответ на
четыре PNG-состояния. Реализация экрана разрешена. Макеты не являются
проверкой качества алгоритма; фактические снимки и проверки сохраняются отдельно.

Это **неproduction**-макеты для обязательного визуального согласования до
реализации. Они используют только отслеживаемую проектную иллюстрацию
`assets/mode-clipart.png`; это подписью отмечено прямо на холсте и не является
демонстрацией качества будущей маски. Пользовательские изображения, API и
генерация изображений не используются.

## Экран и состояния

| Артефакт | Что проверяет |
| --- | --- |
| `default-populated-1120x780.png` | Редактор открыт с готовым автоматическим контуром; поверхность не перегружена узлами. |
| `selected-roi-nodes-1120x780.png` | Локальный ROI вокруг чашки, автоматическая замкнутая кривая, 7 перетаскиваемых точек и 3 рукоятки. |
| `error-no-contour-1120x780.png` | Алгоритм не уверен в области: спокойное предложение выбрать другую область или вернуться. |
| `missing-image-1120x780.png` | Исходный результат перемещён/удалён: можно открыть отдельный PNG, не подменяя исходник. |

## Предлагаемое поведение

- `Автоконтур` строит редактируемый Bézier-контур в выбранной локальной области,
  не меняя RGB-пиксели. Узлы и рукоятки тянутся мышью; панорамирование и масштаб
  не являются изменениями маски.
- `Восстановить` и `Убрать` переключают кисть, которая меняет альфа-маску только
  внутри ROI. Размер кисти задаётся отдельно.
- Растушёвка имеет честные фиксированные значения `0 px` (по умолчанию), `1 px`
  и `2 px`; нулевое значение сохраняет резкий край.
- Просмотр меняет только подложку: шахматка, чёрный или белый. Кнопки истории
  дают отмену/повтор; в макете `Повторить` выключена, пока нет отменённого шага.
- `Применить локально` является единственным главным действием. Он записывает
  правку в текущий результат; `Отмена` закрывает редактор без применения. При
  ошибке или отсутствующем изображении действие применения выключено.

## Визуальное направление

Тёмный компактный рабочий стол Vibix: `#101827` для фона, `#1f2937` для
поверхностей и единственный бирюзовый CTA `#2dd4bf`. Контур использует более
светлый циан только как инструмент точности.
Сигнатурный приём: контур остаётся спокойным, пока пользователь не выбрал ROI,
после чего узлы и рукоятки делают ручной контроль очевидным без отдельного
объясняющего режима.

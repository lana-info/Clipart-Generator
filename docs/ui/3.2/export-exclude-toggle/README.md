# Исключённую из наборов картинку можно вернуть (2026-10-30)

Задача владельца 2026-10-30 (модуль Авто-клипарт). Экран — «Проверка PNG» шага наборов/экспорта.

## Что не так сейчас — `было-исключено.png`

Картинку исключили из наборов (кнопкой «Исключить из наборов» или сняв галочку в таблице наборов).
После этого на этом экране:

- на миниатюре рисуется только перечёркнутый круг «⊘» — он **перебивает метку**: «Ок», «Брак
  генерации», «Брак вырезания» можно нажимать сколько угодно, метка на картинке не появится;
- подпись и подсказка всегда «Исключено из наборов», какую метку ни поставь;
- кнопка «Исключить из наборов» и кнопка «Редактировать прозрачность» **гаснут** (по признаку
  «картинка исключена») — нажать нельзя, как владелец и описала;
- вернуть картинку в наборы с этого экрана **нечем**: кнопка, которая исключила, выключена.

## Что предлагается — `стало-исключено.png`

1. **Кнопка-переключатель.** У картинки в наборах — «Исключить из наборов»; у исключённой —
   та же кнопка с надписью «Вернуть в наборы». Нажатие возвращает картинку **во все её наборы**
   (то же, что поставить галочку в таблице наборов).
2. **«Редактировать прозрачность» доступна всегда** — и у исключённой картинки тоже. Гаснет
   только на время, пока идёт экспорт (как и сейчас).
3. **Метка остаётся видимой у исключённой картинки**: значок метки (✓ / Г / В / ✕) на месте,
   в правом верхнем углу; исключение показано отдельным маленьким значком «⊘» в левом верхнем
   углу, миниатюра остаётся приглушённой (но слабее, чем сейчас: 0.35 → 0.55, чтобы метка читалась).
4. **Подпись/подсказка говорит и то, и другое**: «Исключено из наборов · Брак вырезания».

## Что не меняется

- В наборы попадают только картинки, подтверждённые «Ок» (правило SET-0 владельца 2026-10-28).
- «Ок» сам по себе **не** возвращает картинку в наборы — решение владельца 2026-10-30: метки и
  наборы независимы, возвращает только кнопка.
- Таблица наборов на шаге «Наборы» работает как раньше: галочку можно поставить и снять там.

## Какое действие владельца экран должен поддерживать

Выбрать картинку → «Исключить из наборов» → передумала → та же кнопка «Вернуть в наборы» возвращает
её в наборы; «Редактировать прозрачность» доступна в обоих состояниях.

## Файлы

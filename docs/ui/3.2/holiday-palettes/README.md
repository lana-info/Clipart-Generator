# Holiday palette UI — Studio 3.2

Owner-approved direction from 2026-09-12:

- palette cards show exactly five visible colors;
- holiday palettes use recognizable theme-linked colors, especially classic American Christmas and Halloween;
- first screen area recommends palettes from the current theme/context;
- full library is grouped by Holidays, Seasons, Nature, Color Families and Use;
- custom HEX input and palette-from-reference remain available;
- Mother’s Day and Father’s Day are not first-wave Holiday Profiles;
- holiday context also enriches accessories, props, decor, compositions, mood and background hints while preserving the main theme.

`christmas-1120x780.png` is the real Qt implementation proof at the target 1120×780 geometry. The earlier approved concept was shown in chat; this implementation incorporates the follow-up decision to reduce cards from six colors to five and to use canonical holiday colors.

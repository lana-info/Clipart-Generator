# Автоматический Clipart: стиль, палитра, референсы и подбор идей

Макеты одобрены владельцем в чате 2026-09-28. Цель: убрать дублирующий блок рекомендаций стилей, показывать примеры стилей и сочетаний цветов, явно разделить выбранное оформление и референсы, разрешить пропуск референсов, упростить стоимость AI-подбора и подсказать действие после подготовки идей.

## Визуальные состояния

- `proposed-style.svg`: библиотека стилей, собственная формулировка и палитры.
- `proposed-references-empty.svg`: необязательный шаг без изображений.
- `proposed-reference-sources-default.svg`: выбранные стиль и палитра сохраняются при добавлении изображения.
- `proposed-reference-sources-overrides.svg`: пользователь отдельно выбирает стиль и цвета референса.
- `proposed-cost.svg`: короткое подтверждение с ориентировочной стоимостью.
- `proposed-objects-ready.svg`, `proposed-objects-expanded.svg`: переход к промптам или просмотр всех идей.
- `actual-style-1120x780.png`, `actual-palettes-1120x780.png`, `actual-references-empty-1120x780.png`, `actual-references-1120x780.png`, `actual-references-override-1120x780.png`, `actual-references-bottom-1120x780.png`, `actual-objects-1120x780.png`: реальные экраны Qt при 1120×780, локальные фиктивные данные.
- `actual-cost-dialog.png`: реальное диалоговое окно ориентировочной стоимости с кнопками «Запустить» и «Отмена».
- `actual-model-launch-1120x780.png`: экран выбора модели с референсами после удаления повторной вкладки стоимости; неактивный для этих промптов выбор модели скрыт.
- `style-previews-contact.jpg`: обзор 19 финальных миниатюр.

Реальная ширина автоматического потока меньше ширины отдельного диалога из макета из-за бокового списка шагов. Поэтому карточки перестраиваются в две колонки при ширине содержимого меньше 950 px. Референсы прокручиваются по вертикали; кнопка пропуска видна без прокрутки.

## Правило сочетания оформления и референса

По умолчанию выбранные на шаге 2 стиль и палитра остаются основными. Новый референс явно выбирает признак «Предмет»; его можно заменить или дополнить персонажем, позой, композицией либо настроением. Источник стиля и источник палитры выбираются отдельно. Для каждого из них может быть один активный референс. Если выбран стиль референса, текстовый планировщик перестаёт использовать профиль стиля из библиотеки; промпт генерации просит следовать стилю указанного изображения. Если выбраны цвета референса, локальный анализ изображения получает до пяти доминирующих HEX-цветов для промпта. Выбранные ранее стиль и палитра остаются в редакторе и возвращаются при переключении источника назад. Кнопка пропуска отключает референсы в текущем наборе, сохраняя сами файлы и их настройки в проекте.

Активные изображения передаются модели генерации после отдельного подтверждения. В автоматическом текстовом подборе идей изображения не передаются, учитываются только написанные пользователем заметки. Модель генерации может интерпретировать визуальный референс шире текстовой инструкции; абсолютное копирование только отмеченных признаков не гарантируется. Локальное извлечение палитры из непрозрачной фотографии может включить цвета её фона.

## Миниатюры стилей

Использован встроенный `image_gen`. Общий сюжет каждого промпта: небольшая дружелюбная рыжая лиса рядом с одним цветком, целиком в квадратном кадре, светлый фон, без текста, водяных знаков и рамки. Различается художественная техника согласно `studio_style_profiles.py`: акварель, гуашь, рисунок от руки, маркерный doodle, графитный карандаш, минимальный line art, плоская графика, стикер, пиксельная графика, kawaii, chibi, книжная иллюстрация, pastel nursery, whimsical, скандинавский фолк, винтажная иллюстрация, cottagecore, retro и тёмная готика. Исходные генерации уменьшены до 256×256 JPEG для поставки; финальные файлы находятся в `assets/style_previews/`. Это иллюстративные образцы техники, а не обещание точного результата пользовательской генерации.

## Выбор модели и стоимость перед запуском

В автоматическом наборе вкладка «Проверка и стоимость» удалена: перед кнопкой «Создать изображения» остаются «Промпты» и «Модель». Для промптов с референсами показывается поле «Модель с референсами» и их количество; когда все промпты с референсами, неиспользуемый выбор модели без них скрыт. Поле числа вариантов остаётся доступным. Подтверждение запуска вычисляет оценку по текущим промптам, выбранной модели и обработке, а также называет модель, которая реально получит каждый тип промпта. Для Fal.ai цена без отдельного запроса к провайдеру может остаться неполной; это прямо обозначается.

## Проверка

Целевые Qt и логические тесты: 101 passed, 4 deselected (тесты сборки артефакта не запускались без отдельной команды владельца). Проверены полнота миниатюр, сохранение выбора, влияние источников стиля/палитры, отключение и пропуск референсов, отсутствие передачи отключённых изображений, краткий текст стоимости и путь до генерации. Снимки экранов получены локально с `QT_QPA_PLATFORM=offscreen`. Нативная Windows-сборка и реальный платный запрос не запускались.

## Окно коррекции прозрачности

Первый вариант с кнопкой внутри редактора владелец отклонил. Затем в чате
2026-09-28 был одобрен исправленный макет с системной кнопкой разворачивания
рядом с крестиком: `proposed-transparency-native-windowed-1080x724.png` и
`proposed-transparency-native-maximized-1120x784.png`. Инструменты справа
остаются видимыми. Реальные снимки содержимого после реализации:
`actual-transparency-native-windowed-content-1080x720.png` и
`actual-transparency-native-maximized-content.png`. Linux offscreen не рисует
системный заголовок; наличие нативного флага и переходы размера проверены Qt
тестом. Offscreen виртуальный экран имеет ширину 796 px, поэтому снимок
развёрнутого состояния уже целевых 1120 px. Проверка настоящего заголовка
Windows остаётся для нативного запуска без сборки в этой среде.

## Автоматическое удаление фона

На двух пользовательских Qwen PNG обнаружен сплошной фактурный бумажный фон,
хотя промпт просил ровный ключевой цвет. Их исходники не входят в репозиторий.
Если локальный Chroma Key отклоняет такой фон, только автоматический Clipart
пробует локальную модель U2Net. Маска пороговая и сдвинута внутрь на 4 px,
чтобы не оставить размытую белую кайму. На обоих примерах локально получена
бинарная прозрачность. Если модель недоступна или не выделила объект, файл
остаётся с явным статусом ручной коррекции. Мелкие внутренние просветы и
тонкие детали требуют визуального осмотра. Первый запуск U2Net загружает
локальные веса; платный API для этого не вызывается.

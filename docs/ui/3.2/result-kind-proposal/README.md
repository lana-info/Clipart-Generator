## Что меняется и зачем

Текущий экран проверки показывает общие этапы для всего запуска. Предлагается
таблица элементов с явным назначением и панель маршрута выбранной строки:
пользователь видит, у какого изображения удалится фон, а у какого сохранится.
Назначение не угадывается по тексту. Цвета повторяют тёмную палитру Vibix,
1120×780, без новой боковой навигации; основной акцент на выбранном элементе
и единственном действии запуска. Макет выполнен по frontend-design с сохранением
проектного оформления, не с заменой PyQt на веб-стек.

Сохраняются проекты, настройки API, редактирование промптов, выбор модели на
предыдущем шаге и проверка перед оплатой. Holiday, персонажи, пресеты и
редактирование палитры остаются в конструкторе. Junk Journal является отдельным
будущим модулем, а не новой активной опцией этого списка. Рамки/венки требуют
сначала отдельной политики отверстий. Смешанный набор на макете иллюстрирует
запланированные типы результатов, не доказывает готовность Patterns/seam QC.

## Предлагаемые взаимодействия

Выбор строки обновляет только правую панель. Изменение назначения сохраняется
в проекте и пересчитывает стадии/стоимость, не запускает API. При смене типа
ручной промпт не затирается: несовместимое указание фона получает конфликт.
«Изменить в стиле» возвращает к палитре; модель меняется на шаге настройки
генерации с проверкой совместимости. При пустом наборе, конфликте или отсутствии
необходимого ключа запуска нет. Полученный RGBA не означает Ready без QC.

После утверждения нужно реализовать реальные controls, единый расчёт стадий
для UI/worker/preflight, клавиатурную навигацию и доступность, затем снять
настоящий экран и сравнить с утверждёнными состояниями. Макет не является
проверкой поведения кнопок. Одобрение этого экрана не одобряет другие новые UI.

# Перенос функций 3.1.1–3.1.4: макеты на утверждение (2026-10-23)

Видимые части линии хотфиксов 3.1.x, которых нет в 3.2. Реальные виджеты 3.2, данные — вымышленные.
Скрипты: `python render_c.py <repo> <out>` (так же d, h). Код — только после «утверждаю».

- **C. Проблемные файлы** (3.1.1 9d41228). `C0` сейчас → `C1`: кнопка «Проблемные файлы (N)» в нижнем ряду
  результатов, только когда есть ошибки или остановленные файлы. `C2`: окно — итог, файл, этап, причина, попыток;
  «Скопировать список», «Сохранить как .txt…» (UTF-8, без полных путей).
- **D. Лимит 8 МБ Fal.ai Background Remover до запуска** (3.1.1 6a67834). `D0` сейчас → `D1`: красный блок на «Проверка
  и запуск» с именами и размерами файлов и тремя выходами; «Запустить» недоступна. Файлы с готовой прозрачностью не
  проверяются.
- **H. Код ошибки лицензии** (3.1.4 ba0c153). `H-both`: слева сейчас, справа — код ошибки (без ключа и личных данных) и
  «Скопировать код ошибки».

Уже перенесено без видимых изменений (PR #37–#40): целостность итогового PNG, резкость без ореола, повторы сохранения,
быстрое добавление больших файлов.

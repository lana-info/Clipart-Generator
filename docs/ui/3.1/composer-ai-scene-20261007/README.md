# Конструктор: варианты и выбранный режим

Макеты одобрены владельцем 2026-10-07. Последующие уточнения: убрать «Отменить AI»
полностью, убрать повторения под формами, общие действия без имени объекта,
заметная верхняя кнопка случайных параметров. Текущая реализация учитывает их.

`current-scene.png`, `proposed-*.png` и `actual-randomize-top.png` сохранены как
история обсуждения. Старый proposed-ai-running показывает отмену, которую
владелец позднее попросил удалить; он не описывает итоговую реализацию.

Фактические снимки Qt 1120×780 без сетевых запросов:

- actual-scene-image.png / actual-scene-reels.png: выбранный режим, заголовок,
  центрированные кнопки с цветом и галочкой, поля текущего режима.
- actual-templates-image.png / actual-templates-reels.png: переключатели шаблонов.
- actual-details.png / actual-details-empty.png: верхняя кнопка случайных параметров,
  варианты и placeholder пустого поля.
- actual-ai-running.png: статус выполняемого запроса без кнопки отмены.

Конфигурация/проверки снимков в actual-captures.json. Использованы встроенные
примерные данные; шаблоны не изменены. Снимки подтверждают интерфейс Linux Qt,
не успешный платный AI-запрос и не работу установленной Windows-сборки.
Функциональные проверки и ограничения приведены в STATE.md.

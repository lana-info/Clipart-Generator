# Task 1 — provider/model selector

`approved-owner-direction.png` фиксирует согласованное направление экрана:
один список моделей с явной подписью provider (`KIE — …` или `Fal.ai — …`),
общие controls пропорции, разрешения и числа вариантов.

Референсы не получают отдельную панель настроек. Когда batch содержит
референсы, список и запуск допускают только совместимые модели.

Перед реализацией необходимо показать ещё состояния с референсами и с
недоступной выбранной моделью; после реализации — сопоставить реальные
screenshots с этим направлением.

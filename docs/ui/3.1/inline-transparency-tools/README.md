# Единый редактор прозрачности

Владелец одобрил реализацию 2026-09-23 после макета и следующих уточнений:
иконки кисти/пера без заголовка, кисть и «Убрать» по умолчанию, диаметры
2/6/10/16/32/64 px, жёсткость 85%, образцы фона без текста, горячие клавиши.

Реализовано в `v3_transparency_preview.py`. Вместо вложенного диалога используется
тот же QGraphicsView и MaskEditDocument. Алгоритм локальной правки маски из
studio_contour сохраняет отверстия, другие объекты и нетронутые детали.
Автоконтур извлекает все границы из текущей альфа-маски, включая отверстия.
Он не восстанавливает форму по RGB. Предел активного редактора: 4100 px по каждой стороне.

## Управление

- B/И: кисть, P/З: перо. Активные кнопки выделяются.
- + или = / −: диаметр кисти по готовым размерам; цифровой блок тоже поддержан.
- Ctrl + / Ctrl −: масштаб изображения. Пробел + мышь: перемещение.
- Alt при рисовании: временно противоположное действие кисти.
- Клик по точке: выбрать; перетаскивание точки/направляющей: изменить.
- Двойной клик по линии: добавить точку без изменения формы кривой.
- Delete/Backspace: удалить выбранную точку, сохраняя минимум три.
- Alt+клик по точке: плавная/угловая. Стрелки: 1 px, Shift+стрелки: 10 px.
- Enter или «Применить контур»: применить к маске.
- Ctrl+Z / Ctrl+Shift+Z: отмена/повтор. В пере сначала отменяются правки
  ещё не применённых точек; применённый контур и кисть используют историю маски.

Переключение инструментов сохраняет масштаб, документ и ещё не применённый контур.
Контур также сохраняется при переходе между файлами. «Сохранить PNG» применяет
незавершённый контур и сохраняет PNG и альфа-маску существующим безопасным способом.
Горячие клавиши инструментов обрабатываются холстом, не перехватывая текстовые поля.

## Фоновые расчёты и 4100×4100

Владелец одобрил расширение предела и отмену 2026-09-23. Расчёт выполняется
в отдельном потоке на снимке маски. До завершения доступны зум/перемещение,
но изменение маски заблокировано. Активная кнопка превращается в «Отменить»;
работает Esc. [Состояние расчёта](actual-busy-1120x780.png).
Отмена кооперативная: текущий вызов OpenCV завершается, затем задача прекращается;
даже если результат уже рассчитан, отменённая/устаревшая задача его не публикует.
Смена файла, закрытие или скрытие редактора также отменяют отложенное сохранение.

[Измерения](benchmark-4100.json): отдельные процессы Qt offscreen на Linux,
6 виртуальных ядер AMD EPYC. Сложный пример4100:1255 точек,0.127с построение,
0.261с применение,584.5МиБ пикового RSS процесса,53.5мс максимальный интервал
между событиями таймера UI. Простая4096:0.086с/0.122с,599.3МиБ.
Это синтетические примеры и отдельный редактор; не гарантированное время
для любого изображения и не минимальные требования полной Studio.

Локальная растеризация проверена на точное равенство полной для перемещения,
сглаживания с явными и автоматическими направляющими, добавления/удаления и
границы отверстия. Обнаружена и исправлена зависимость округления полупикселей
от нечётного смещения ROI. Убрано PNG-кодирование при обновлении Qt-превью.
Сохранены ограничения сложности: число контуров и узлов; шумная маска может
не пройти их даже при допустимом размере изображения.

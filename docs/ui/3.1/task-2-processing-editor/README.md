Владелец утвердил `approved-mockup.png` 29 августа 2026 года.

Экран сохраняет компактный список операций сверху. Ниже отображаются только
включённые этапы в фактическом порядке обработки: короткий заголовок, controls,
тонкий разделитель и небольшой интервал. Длинный набор этапов прокручивается;
выключенная операция не создаёт пустого блока параметров.

Задача должна использовать один `ProcessingPipelineEditor` в Clipart и
Processing. После реализации реальные screenshots обоих маршрутов сравниваются
с этим макетом.

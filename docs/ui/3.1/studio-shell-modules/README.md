# Каталог VIBIX Studio с установкой модулей

Основной экран понравился владельцу 2026-09-29; по его уточнению убрана панель
статуса/кнопка «Обновить доступ», а «Обновления модулей» перенесены к «Лицензия». Это макеты, не работающая реализация.
Тестовые данные, без API-запросов и изменений лицензий. Цель: единый каталог пяти
модулей, скачивание по существующим серверным правам, без покупки внутри приложения.

«Скачать» получает совместимый подписанный пакет и необходимые общие компоненты;
после успешной установки появляется «Открыть». «Нет доступа» не является ссылкой,
не предлагает оплату и не выдаёт прав. При неизвестных правах предлагается проверка.
«Ожидается выпуск» отличается от отсутствия права: приложение не обещает скачивание
несуществующего пакета. Установленный модуль сохраняет «Открыть» при доступном обновлении;
обновление выполняется через верхнюю кнопку «Обновления модулей».
Права обновляются автоматически при запуске и после смены лицензии. Повреждённый или несовместимый пакет
не открывается. Новую совместимую версию можно проверить через «Обновления модулей»;
переустановка повреждённой версии с тем же номером пока не автоматизирована.
Отмена/обрыв не заменяет рабочую версию. При отсутствии интернета открытие допускается
только в пределах уже существующего подписанного права и текущих правил сервера.

Настройки API, проекты, новости и диагностические инструменты сохраняются. Ключи и
данные пользователя не попадают в модульные архивы. Новые права Club/VIP не выводятся
по названию набора: приложение использует точный подписанный список сервера.

Перерисовка: `QT_QPA_PLATFORM=offscreen /tmp/clipart-ui-venv/bin/python docs/ui/3.1/studio-shell-modules/preview.py`.

Уточнение владельца: сохранить прежние изображения и их размер (112 px в компактной
карточке). Для конструктора создана отдельная обложка с игровым автоматом идей,
`assets/studio-prompt-composer-cover.png`. Это оформление карточки, не изменение
пошагового конструктора и не функция азартной игры.


## Реальная реализация, проверка Qt

[Каталог после правок](actual-mixed.png), [чистая установка](actual-empty.png),
[офлайн](actual-offline.png), [пакет ещё не опубликован](actual-not-published.png).
Снимки реальных компонентов Qt1120×780, тестовые состояния, без пользовательских
данных. Прежние иллюстрации и высота112px сохранены. Новая обложка конструктора
показывает автомат с яблоком, цветком и облаком. Подпись сокращена до «7 вариантов:
изображения и Reels», чтобы не обрезаться при поддерживаемой ширине.

Установка использует существующее окно модулей: одно нажатие «Скачать» на карточке
открывает его и запускает только выбранную установку. Прогресс и отмена находятся
в этом окне; отдельная полоса в карточке из первоначального макета не реализована.
Новости и сохранённые проекты остаются в прежнем расположении. Это отличия от
эскиза, которые следует учитывать при окончательной визуальной приёмке.
Проверки кнопок, отмены после staging, прав и реального HTTPS скачивания пройдены.
Установленное Windows приложение на этом checkpoint пока не проверено.

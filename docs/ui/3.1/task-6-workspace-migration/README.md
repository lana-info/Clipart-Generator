# Task 6 — безопасная миграция рабочей папки

`mockup.svg` и `mockup.png` — макет обязательной одноразовой страницы для
старого сохранённого пути, который не оканчивается на literal `output`.
Реализация страницы до утверждения владельцем не начинается.

## Поведение

- По умолчанию выбран безопасный рекомендуемый вариант: считать старый путь
  workspace root и далее сохранять готовые PNG в его `output/`.
- Второй вариант открывает системный выбор другой рабочей папки. Пока папка не
  выбрана, переход дальше недоступен.
- Страница прямо сообщает, что существующие файлы не перемещаются и не
  удаляются. `rough/`, `output/` и `.run/` создаются только после подтверждения.
- Literal legacy path с basename `output` не показывает эту страницу: он
  мигрирует в parent с компактным одноразовым уведомлением по `CG31-FR-020`.
- При минимальном окне 980×700 правая колонка остаётся прокручиваемой, карточки
  сохраняют вертикальный порядок, а footer остаётся доступным.

## Состояния для реализации после approval

1. Рекомендуемый текущий root выбран — `Продолжить` доступно.
2. Выбран другой root — карточка показывает новый путь, `Продолжить` доступно.
3. Системный выбор отменён или папка недоступна — остаёмся на странице, выводим
   краткую ошибку под второй карточкой, фактический output не меняется.

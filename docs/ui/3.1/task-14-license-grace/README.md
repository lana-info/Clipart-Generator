# Task 14 — временный автономный доступ

Утверждено владельцем 2026-08-29.

- `approved-main.png` — ранее подтверждённая лицензия работает при временной
  недоступности сервера; показаны последняя проверка и дата окончания grace.
- `approved-expired.png` — после семи календарных дней новые операции
  блокируются до повторной проверки через интернет.
- `implemented-main.png` и `implemented-expired.png` — реальные offscreen
  screenshots реализованного PyQt6-интерфейса для сопоставления с макетом.

Граница поведения: первая активация, явный отказ сервера, истёкшая лицензия,
повреждённое состояние и перевод системных часов назад не получают offline
доступ. Лицензионный ключ не показывается и не сохраняется в grace-state.

# Две общие кнопки края: история макетов и проверка

Запрос владельца: две соседние кнопки-иконки над кистью/пером; слева
ступенчатая линия (Чётче), справа плавная дуга (Сгладить). Tooltips редактора
сократить до одного-двух слов, доступные названия сохранить.

current.png: существующий редактор. proposed.png: предложенное размещение
1120×780. empty-disabled.png: без файла оба действия недоступны.
Изображение круга синтетическое, это только макет controls, не результат
нового алгоритма. Исходники приложения не менялись.

Предложение поведения: один клик сглаживания сразу изменяет alpha только
в узкой области кромки, RGB сохраняется, шаг отменяется existing Undo/Redo.
Не выполнять общий blur объекта. При незавершённом контуре/расчёте действия
блокируются; no-op не создаёт историю. Явное сохранениеPNG остаётся.
Тонкие детали и внутренние просветы требуют проверки на ослабление.
Алгоритм и результат ещё не реализованы и не проверены.

## Окончательный согласованный смысл и новый макет

Владелец одобрил: общие кнопки Чётче/Сгладить, область по наличию выделенных
точек, иначе весь край. Не путать активное лассо с существующим выделением.
Сглаживание снизу удаляется; Упростить остаётся. Обе edge операции применяются
сразу, существующие Undo/Redo и явное сохранение. Обрабатывать alpha, RGB не менять.
Индикатор перенесён вниз только под изображение, не под всю ширину страницы.
Он показывает активность без выдуманных процентов; отмена отдельная.

final-brush.png: весь край, кисть и её настройки.
final-pen.png: группы Масштаб/Край/Инструмент/Контур, иконка Лассо, только Упростить.
final-selection.png: реальный извлечённый synthetic contour и3selected nodes;
под edge кнопками «Выделенный участок» вместо «Весь край».
final-busy.png: полоса активности под изображением, conflicting controls disabled.
final-empty.png: нет файла, действия недоступны.
Все изображения1120×780, actualQt mockup; это не реализованные edge операции.

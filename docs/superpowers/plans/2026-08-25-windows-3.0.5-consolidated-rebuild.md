# Windows 3.0.5 Consolidated Rebuild Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Produce one verified Windows 3.0.5 installer containing the approved artwork, the latest intended UX changes, and no visible helper-process console windows.

**Architecture:** Keep `codex/fix-packaged-mode-artwork` as the release line because it contains the later packaging/runtime fixes and approved artwork. Port the bounded user-facing changes from divergent commit `82fe6ff` file-by-file; do not merge `codex/tech-debt-11` wholesale. Extend the Windows pipeline so both the PyInstaller tree and the Inno-installed copy prove artwork loading and emit visual evidence before the installer artifact is accepted.

**Tech Stack:** Python 3.12, PyQt6, PyInstaller, Inno Setup, GitHub Actions on `windows-latest`.

**Spec:** `TASKS_3.0.ru.md`, `STATE.md`, `docs/brand/VIBIX_PRODUCT_FAMILY_HANDOFF.md`, and owner acceptance in the current task.

## Global Constraints

- The requested installer version remains exactly `3.0.5`.
- Do not upload or publish a `3.0.5` revision to the license server.
- Build Windows only; do not run the macOS job.
- Preserve the approved `assets/mode-*.png` and `assets/installer-wizard-hq.png` hashes.
- No application-launched local helper may create a visible console window.
- Preserve licensing, update verification, local-processing, and cancellation behavior.
- Do not merge the divergent branch wholesale; port and test bounded changes.

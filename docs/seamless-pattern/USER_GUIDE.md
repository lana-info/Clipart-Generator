# Patterns: руководство пользователя

Patterns собирает бесшовные узоры для продажи: из ваших PNG-рисунков с прозрачным
фоном или из готовой плитки, которую нужно «починить». Платных запросов нет, ваши
исходные файлы не изменяются. Версия модуля 1.6.4, нужна Studio 3.2.39 или новее.

## Как открыть

1. Обновите Studio до 3.2.39 или новее.
2. Откройте «Обновления модулей» (или нажмите на карточку «Паттерны») и установите модуль. Если карточка
   «Паттерны» показывает «недоступен», у вашей лицензии нет права на модуль или он ещё
   не опубликован: обратитесь к администратору.
3. Откройте карточку «Паттерны» на главной Studio.

## Пять шагов (слева в окне)

1. **Источник.** Выберите «Из ваших PNG» (добавьте файлы кнопкой «Добавить PNG» или
   папку кнопкой «Добавить папку») или «Из готовой плитки» (кнопка «Выбрать плитку»).
2. **Настройки.** Для PNG: раскладка (прямая, Half-drop, Brick, Зеркало), количество и
   размер элементов, зазор, поворот, фон («Прозрачный», «Тёплый белый» и др.), размер
   листа в дюймах. Для готовой плитки: ширина полосы смешивания и сглаживание шва;
   Half-drop и Brick там недоступны.
3. **Предпросмотр.** Узор показан 3 × 3, стык листов находится в центре картинки. Под
   ним оценка шва: Ready (можно продавать как бесшовный), Review (проверьте глазами) и
   Fail (шов виден). «Увеличить шов» показывает стык крупно. Для плитки с заметным швом
   нажмите «Сделать бесшовной»; результат всегда можно оставить как есть («Оставить
   как есть (Review)»).
4. **Набор.** Соберите несколько листов: «Добавить лист в набор», «Пересобрать»
   (новый seed, при том же seed результат повторяется), «Закрепить» (запомнить
   текущую расстановку при пересборке). Каждый лист — отдельный файл.
5. **Экспорт.** Выберите папку кнопкой «Выбрать папку…», формат и размер, затем
   «Экспортировать». Файлы называются «Имя набора NN.png». Существующие файлы молча не
   перезаписываются: программа сообщит, какие файлы уже есть. Листы Review,
   созданные автоматически, в экспорт не входят; лист, добавленный вами вручную, входит.

## Важно знать

- Оценка шва — подсказка, а не гарантия. Пороги Ready/Review/Fail пока временные;
  перед публикацией набора посмотрите стык в предпросмотре.
- Рисунки на прозрачном фоне подходят лучше всего. Если места на листе не хватает,
  будет показано, сколько элементов поставлено из запрошенных.
- Генерации плитки через ИИ в этой версии нет; перекраски по палитре тоже нет.
- Файлы проекта и экспорт хранит Studio; при отсутствии модуля (например, права
  закончились) проекты остаются сохранёнными и снова откроются после возвращения права.
- При ошибке откройте «Диагностика» в окне и приложите экспорт к обращению.

*Описание сверено с кодом страницы; реальную проверку на Windows (T5.2) делает владелец, после неё руководство нужно перечитать.*

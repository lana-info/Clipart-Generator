## Этап 1. Движок (без Qt, без сети) — расширение `studio_patterns.py`
- [x] T1.0 Решено иначе: исходники движка остаются в корне репозитория (с тестами), а
  подписанный пакет собирается из их копий с относительными импортами
  (`studio_patterns_package.patterns_payload`). Переносить файлы не нужно.
- [x] T1.1 Wrap-aware ресемплинг (pad по периоду → фильтр → crop) + oracle-тест;
  предпосылка для экспорта, превью и режима B.
- [x] T1.2 `layout` (mirror добавлен в `RepeatMode`; half-drop/brick уже были): straight / half-drop / brick (есть) + mirror; размеры базовой
  ячейки для квадратного supertile; тесты на стыки против lattice-oracle.
- [x] T1.3 `layout_scene` (вместо `tile_from_motifs`): плотность и зазор на торе, частоты, закрепление,
  ограниченные попытки с предупреждением; seed.
- [~] T1.4 `seam_report` (непрерывность через шов относительно внутренней
  статистики) + размеченный эталонный набор good/bad; калибровка порогов
  Ready/Review/Fail до T1.5.
- [x] T1.5 `make_seamless`: offset + feathered blend без уменьшения размера;
  исследовать graph-cut шов; v1 только straight (+ mirror).
- [x] T1.6 `tile_preview` 3×3 / 5×5 с бюджетом пикселей, стык в центре.
- [x] T1.7 `export_tile`: размеры, 300 DPI (допуск pHYs), sRGB, PNG/JPG (без альфы в JPG),
  оценка размера файла, атомарная запись.
- [—] T1.8 `recolor` — вне v1 (решение владельца).
- [x] T1.9 Тесты: детерминизм по seed (попиксельно), граничные размеры, лимиты
  входа, отсутствие мутации входных файлов. T-PERF: замер 3600×3600 и пиковой памяти.

Статус этапа 1 (2026-10-22): код в `studio_patterns_tools.py` и `studio_patterns.py`,
тесты `tests/test_studio_patterns_tools.py`. Замер 3600×3600 (VDS): рендер 0.5–1.2 с,
seam_report 0.9 с, make_seamless 1.6 с, экспорт PNG 3.1 с / JPG 1.5 с, пик памяти
~373 МБ — укладывается в цель < 10 с. `[~]` T1.4: пороги Ready/Review/Fail
(`SEAM_READY_MAX`, `SEAM_REVIEW_MAX`) временные; их нужно откалибровать на реальных
хороших и плохих плитках владельца до приёмки. «Двоение» в полосе смешивания
метрикой пока не измеряется (graph-cut шов в T1.5 не исследован).

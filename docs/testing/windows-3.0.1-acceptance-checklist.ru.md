# Чек-лист проверки Vibix Images 3.0.1 на Windows

Этот чек-лист предназначен для ручной проверки последнего установщика перед
публикацией обновления. Он не разрешает публикацию релиза, использование платных
API или изменение реальных лицензий без отдельного решения.

## Проверяемый файл

- Имя: `VibixImages-Setup-3.0.1.exe`
- Источник: Azure Pipelines, успешная сборка `20260817.3`, run `10`
- Размер: `164801305` байт (примерно 164,8 МБ)
- SHA-256:
  `719847fcc0c678404766b0fc3f94ffd7777b7688e9aa710e314ad4409aa16b27`
- Продукт лицензии и обновлений: `clipart-generator`
- Канал: `stable`
- Платформа: `windows-x64`

Если имя, размер или SHA-256 отличаются, остановить проверку и не публиковать
файл: это другой установщик, даже если на нём также написано `3.0.1`.

## Как отмечать результат

- `PASS` — ожидаемое поведение подтверждено.
- `FAIL` — обнаружена ошибка; записать шаги, сообщение и приложить скриншот.
- `BLOCKED` — проверка невозможна без тестовой лицензии, сервера или специальных
  условий.
- `SKIP` — проверка сознательно пропущена с указанной причиной.

Компьютер и результат:

- Дата:
- Проверяющий:
- Windows и номер сборки:
- Разрешение экрана и масштаб DPI:
- Установка новая или поверх старой версии:
- Итог: `PASS / FAIL / BLOCKED`

## 1. Подготовка — обязательно

- [ ] Windows 10 или Windows 11 x64 полностью загружена и работает стабильно.
- [ ] Установщик получен из Azure run `10`, а не из старой сборки 3.0.1.
- [ ] SHA-256 файла совпадает со значением выше. В PowerShell:

  ```powershell
  Get-FileHash .\VibixImages-Setup-3.0.1.exe -Algorithm SHA256
  ```

- [ ] Подготовлена отдельная тестовая лицензия продукта `clipart-generator`.
- [ ] Известно, привязана ли тестовая лицензия к другому компьютеру.
- [ ] Сделана копия важных пользовательских настроек и рабочих файлов.
- [ ] Защитник Windows и SmartScreen не отключены специально ради проверки.

## 2. Новая установка — обязательно

Проводить на компьютере, где Vibix Images ещё не установлена, либо после
контролируемого удаления старой тестовой установки.

- [ ] Установщик запускается двойным щелчком и не сообщает о повреждённом файле.
- [ ] Если SmartScreen предупреждает о неизвестном издателе, записан точный текст
  и сделан скриншот. Для неподписанного установщика такое предупреждение
  ожидаемо и само по себе не означает повреждение файла.
- [ ] После подтверждения появляется стандартный запрос UAC.
- [ ] В мастере установки везде используется название **Vibix Images**.
- [ ] Значок приложения отображается корректно, без старой иконки Clipart
  Generator.
- [ ] Установка в стандартную папку завершается без ошибки.
- [ ] По выбранной опции создаётся рабочий ярлык на рабочем столе.
- [ ] В меню «Пуск» создаётся рабочий ярлык **Vibix Images**.
- [ ] Приложение запускается из мастера установки и отдельно через меню «Пуск».
- [ ] В Диспетчере задач после закрытия не остаются зависшие процессы Vibix
  Images.

## 3. Первый запуск и лицензия — обязательно

- [ ] До ввода или проверки лицензии основное рабочее окно не открывается.
- [ ] Сначала появляется понятный запрос лицензионного ключа.
- [ ] Отмена ввода лицензии закрывает запуск, а не открывает приложение.
- [ ] Пустой ключ не воспринимается как успешная активация.
- [ ] Заведомо неправильный ключ показывает понятную ошибку и не открывает
  приложение.
- [ ] При отключённом интернете приложение сообщает о проблеме соединения, а не
  показывает «лицензия активна».
- [ ] Действующая тестовая лицензия активируется и открывает приложение.
- [ ] Полный лицензионный ключ после активации нигде не отображается.
- [ ] На стартовом экране видны статус лицензии, время последней проверки,
  кнопки «Сменить лицензию», «Настройки API» и «Журнал диагностики».
- [ ] Повторный запуск выполняет свежую онлайн-проверку лицензии.
- [ ] После отключения интернета и нового запуска доступ не разрешается по
  старому сохранённому результату.

Если доступны специально подготовленные тестовые лицензии:

- [ ] Истёкшая лицензия отклоняется без разрешения работы.
- [ ] Отозванная лицензия отклоняется без разрешения работы.
- [ ] Лицензия, привязанная к другому устройству, не активируется как новая.
- [ ] После разрешённого администратором сброса устройства лицензия активируется
  на тестовом компьютере, а старое устройство больше не проходит проверку.

## 4. Интерфейс Windows и DPI — обязательно

Проверить минимум при масштабе Windows 100% и 150%. Если доступно — также 125%
и 200%.

- [ ] Заголовки, кнопки и поля не обрезаются.
- [ ] Текст не накладывается на соседние элементы.
- [ ] Диалоги лицензии, API-настроек и диагностики полностью помещаются на
  экране.
- [ ] Кнопки подтверждения и отмены доступны без изменения масштаба Windows.
- [ ] Иконка приложения чёткая в окне, панели задач, меню «Пуск» и ярлыке.
- [ ] Окно можно свернуть, развернуть, восстановить и закрыть без зависания.
- [ ] На втором мониторе, если он доступен, окно не теряется и сохраняет
  читаемый размер.

## 5. Базовая работа приложения — обязательно без платных операций

- [ ] Отображаются три ожидаемых режима работы.
- [ ] Можно выбрать рабочую папку и папку результатов.
- [ ] После перезапуска выбранные папки восстанавливаются корректно.
- [ ] Новая установка не пытается сохранять результаты в `Program Files`.
- [ ] «Настройки API» открываются, сохраняются и повторно открываются без потери
  несекретных настроек.
- [ ] Секретные ключи не появляются в журнале диагностики.
- [ ] «Журнал диагностики» открывается и показывает текущую сессию без ключей,
  полных ответов API и других секретов.
- [ ] Отмена операции не превращается в сообщение «успешно» или «готово».
- [ ] Повторные Start/Stop и закрытие окна не оставляют зависших процессов или
  временных `.part`-файлов.

Проверку реального платного провайдера выполнять только с отдельного разрешения:

- [ ] `BLOCKED/SKIP` или выполнена одна минимальная реальная операция.
- [ ] При успешном ответе результат действительно создан и открывается.
- [ ] Ошибка API, таймаут или неполный ответ показываются как ошибка, а не как
  пустой успешный результат.

## 6. Повторная установка и обновление поверх старой версии — обязательно

- [ ] Установить предыдущую поддерживаемую тестовую версию.
- [ ] Запустить `VibixImages-Setup-3.0.1.exe` поверх неё.
- [ ] UAC и мастер установки работают без ошибки занятых файлов.
- [ ] После обновления запускается именно версия 3.0.1.
- [ ] Пользовательские настройки, лицензия и рабочие папки не пропали.
- [ ] Старые ярлыки с названием Clipart Generator не создаются повторно.
- [ ] Повторный запуск установщика 3.0.1 не повреждает установленное приложение.
- [ ] Отмена мастера до начала копирования оставляет старую версию рабочей.
- [ ] Принудительное закрытие мастера во время теста не оставляет приложение в
  состоянии, которое невозможно удалить или установить повторно.

## 7. Проверка обновления через сервер — только после подготовки тестового релиза

Не публиковать ревизию в рабочем канале без отдельного подтверждения. Простое
создание черновика не должно делать обновление доступным пользователям.

- [ ] На сервер загружен именно проверенный файл с SHA-256 из этого документа.
- [ ] Ревизия относится к продукту `clipart-generator`, версии `3.0.1`, каналу
  `stable`, платформе `windows-x64`.
- [ ] Размер и SHA-256, вычисленные сервером, совпадают с ожидаемыми.
- [ ] Черновик не предлагается обычному приложению как обновление.
- [ ] Для контролируемой проверки подготовлен разрешённый способ временно сделать
  релиз доступным только тестовой лицензии/среде.
- [ ] Приложение старой версии обнаруживает 3.0.1 после запуска.
- [ ] Выбор «Не сейчас» ничего не скачивает; предложение появляется при следующем
  запуске.
- [ ] Выбор «Обновить» показывает прогресс и скачивает файл полностью.
- [ ] После проверки размера и SHA-256 запускается Windows-установщик, а
  приложение корректно закрывается.
- [ ] Отмена скачивания удаляет частичный файл и оставляет старую версию рабочей.
- [ ] Отключение интернета во время скачивания не запускает частичный файл.
- [ ] После восстановления интернета повторная попытка завершается корректно.
- [ ] Недостаток места на диске показывает ошибку и не сообщает об успехе.
- [ ] Отозванный релиз больше не выдаётся приложению.
- [ ] После установки приложение сообщает, что версия актуальна, и не предлагает
  3.0.1 повторно.

## 8. Удаление и восстановление — обязательно

- [ ] Vibix Images удаляется через «Установленные приложения» Windows.
- [ ] После удаления основной исполняемый файл и ярлыки отсутствуют.
- [ ] Повторная установка после удаления проходит успешно.
- [ ] Если пользовательские настройки сохраняются после удаления, это явно
  зафиксировано; они не должны повреждать повторный запуск.
- [ ] Если установка или обновление завершились ошибкой, повторный запуск
  установщика позволяет восстановить рабочее состояние.

## 9. Что приложить к результату

- [ ] Заполненный чек-лист со статусом каждого раздела.
- [ ] Скриншот SmartScreen и UAC.
- [ ] Скриншоты первого запроса лицензии и стартового экрана после активации.
- [ ] Скриншоты при DPI 100% и 150%.
- [ ] Точный текст каждой обнаруженной ошибки.
- [ ] Журнал диагностики только после проверки, что в нём нет секретов.
- [ ] Версия Windows, шаги воспроизведения и ожидаемое/фактическое поведение для
  каждого `FAIL`.

## Критерий допуска к публикации

Релиз 3.0.1 можно рекомендовать к публикации, когда:

- все обязательные пункты имеют результат `PASS`;
- нет ошибки, позволяющей открыть приложение без свежей действующей лицензии;
- установка и обновление не повреждают предыдущую рабочую версию;
- неподписанный установщик показывает только ожидаемое предупреждение
  SmartScreen, после подтверждения устанавливается и запускается;
- сервер и клиент согласны по продукту, версии, размеру и SHA-256;
- все `BLOCKED`, `SKIP` и найденные дефекты явно перечислены и приняты до
  публикации.

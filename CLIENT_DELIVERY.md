# Клиентская поставка Clipart Generator 3.0

## Что получает пользователь

Один проверенный установщик Windows `ClipartGenerator-Setup-3.0.exe` с приложением версии 3.0, необходимыми runtime-компонентами, моделями и лицензиями. Установщик должен работать без Git, Python, исходников проекта и ручной подготовки папок.

## Что не входит

Не входят `output`, `cache`, `logs`, временные изображения, тестовые данные, `scratch`, служебные документы разработки, git-метаданные, `.env` с секретами и файлы старых релизов.

## Текущее состояние

Поставка **не готова к выдаче**: локальная PyInstaller-сборка не завершилась за контрольные 120 секунд, Inno Setup на машине отсутствует, а `version.json` описывает опубликованный 2.0 update-канал. Поэтому 3.0 installer, checksum и clean-machine first-run пока не подтверждены.

Публичный репозиторий `Clipart-Generator-Updates` и GitHub Release в рамках этой работы не изменяются.

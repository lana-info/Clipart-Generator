# Клиентская поставка Clipart Generator 3.0

## Что получает пользователь

Проверенный Windows installer `ClipartGenerator-Setup-3.0.exe` и macOS ZIP с `.app` с приложением версии 3.0, необходимыми runtime-компонентами, моделями и лицензиями. Пакеты должны работать без Git, Python, исходников проекта и ручной подготовки папок.

## Что не входит

Не входят `output`, `cache`, `logs`, временные изображения, тестовые данные, `scratch`, служебные документы разработки, git-метаданные, `.env` с секретами и файлы старых релизов.

## Текущее состояние

Поставка **не готова к выдаче**: локальная PyInstaller-сборка не завершилась за контрольный интервал, Inno Setup на машине отсутствует, а `version.json` описывает опубликованный 2.0 update-канал. Поэтому 3.0 installer, macOS package, checksum и clean-machine first-run пока не подтверждены.

GitHub Actions должен использоваться только как build-only pipeline в приватном основном репозитории. Автоматическое создание GitHub Release отключено; публикация требует отдельного подтверждения.

Публичный репозиторий `Clipart-Generator-Updates` и GitHub Release в рамках этой работы не изменяются.

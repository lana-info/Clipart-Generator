# Product Backlog

Это каталог будущих идей, а не план и не обещание. Ничего из этого списка не
реализуется в рамках подготовки 3.0.

Формат каждой записи: описание, причина, ценность, пример пользователя,
предполагаемая версия.

## UX

### UX-01 — Контекстная помощь по шагам
- Описание: короткие подсказки и inline-help для каждого шага wizard.
- Причина: новичок не всегда понимает, что требуется до запуска.
- Ценность: меньше ошибок и обращений за поддержкой.
- Пример пользователя: «Почему запуск заблокирован и что исправить?»
- Версия: 3.1

## UI

### UI-01 — Режим компактной/расширенной рабочей области
- Описание: пользователь выбирает плотность таблиц, preview и панелей.
- Причина: разные размеры экранов и предпочтения.
- Ценность: удобство на ноутбуке и большом мониторе.
- Пример пользователя: «Мне нужно видеть больше строк очереди».
- Версия: 3.1

## Performance

### PERF-01 — Фоновая индексация и thumbnail cache
- Описание: кэшировать миниатюры и не перечитывать большие изображения.
- Причина: большие batch сейчас требуют лишних чтений.
- Ценность: быстрее навигация по 50–100 файлам.
- Пример пользователя: «Переход между файлами не должен ждать декодирования».
- Версия: 3.1

## Architecture

### ARCH-01 — Выделить run engine из main.py
- Описание: отделить worker, run events и orchestration от монолитного UI.
- Причина: legacy WorkerThread усложняет тестирование и миграцию.
- Ценность: безопаснее изменения и яснее ownership.
- Пример пользователя: «Обновление UI не ломает обработку».
- Версия: 3.1

## Workflow

### WORK-01 — Сохранённые профили запуска
- Описание: именованные профили настроек для Clipart/Pinterest/Processing.
- Причина: повторяющиеся задачи требуют ручного ввода одних параметров.
- Ценность: быстрее повторный запуск без потери контроля.
- Пример пользователя: «Мой профиль Pinterest всегда вертикальный и 300 DPI».
- Версия: 3.1

## Automation

### AUTO-01 — Watch folder с явным подтверждением
- Описание: обработка новых файлов в выбранной папке по правилам пользователя.
- Причина: ручное добавление batch занимает время.
- Ценность: удобнее повторяющийся локальный workflow.
- Пример пользователя: «Каждый новый экспорт из сканера должен попасть в очередь».
- Версия: 4.0

## AI

### AI-01 — Provider capability advisor
- Описание: объяснять, какая модель подходит под prompt, reference и размер.
- Причина: каталог моделей сложен для новичка.
- Ценность: меньше неудачных платных запусков.
- Пример пользователя: «Почему эта модель недоступна для моего reference?»
- Версия: 3.1

## Pinterest

### PIN-01 — Пакетные Pinterest-варианты с preview grid
- Описание: показывать несколько вариантов рядом до запуска генерации.
- Причина: Pinterest workflow сравнивает композиции, а не один результат.
- Ценность: быстрее выбрать направление.
- Пример пользователя: «Сравнить 10 вертикальных вариантов одной идеи».
- Версия: 3.1

## Clipart

### CLIP-01 — Библиотека reusable prompt templates
- Описание: сохранять, тегировать и искать собственные шаблоны промптов.
- Причина: удачные формулировки часто повторяются.
- Ценность: стабильнее стиль и быстрее batch.
- Пример пользователя: «Повторить серию с тем же стилем и только новой темой».
- Версия: 3.1

## Processing

### PROC-01 — Preview zoom и before/after slider
- Описание: увеличенный preview и интерактивное сравнение до/после.
- Причина: текущий preview недостаточен для мелких деталей.
- Ценность: надёжнее визуальная проверка результата.
- Пример пользователя: «Проверить край прозрачного объекта на 200%».
- Версия: 3.1

## Cloud

### CLOUD-01 — Явный cloud-job center
- Описание: отдельный экран состояния, стоимости и отмены cloud jobs.
- Причина: cloud операции требуют другого ожидания и контроля стоимости.
- Ценность: прозрачность и меньше неожиданных расходов.
- Пример пользователя: «Видеть, сколько задач запущено и сколько это стоит».
- Версия: 4.0

## RunPod

### RUNPOD-01 — Управляемый RunPod backend
- Описание: конфигурируемый endpoint, health check, budget и cleanup.
- Причина: локальная машина не подходит для тяжёлых моделей.
- Ценность: контролируемый доступ к GPU.
- Пример пользователя: «Запустить согласованный тяжёлый pipeline на своём endpoint».
- Версия: Future

## SynthID

### SYNTH-01 — Официально подтверждённый detector research track
- Описание: отдельный исследовательский модуль с evidence и статусом unknown.
- Причина: нельзя обещать универсальное обнаружение/удаление SynthID.
- Ценность: честная provenance-проверка без ложных гарантий.
- Пример пользователя: «Понять, есть ли подтверждённый сигнал, не меняя файл».
- Версия: Future

## Installer

### INST-01 — Повторяемый signed release pipeline
- Описание: единый version source, Windows/macOS artifacts, checksum и signing.
- Причина: текущие packaging metadata требуют ручной синхронизации.
- Ценность: предсказуемый выпуск и обновление.
- Пример пользователя: «Установить новую версию без ручных исправлений».
- Версия: 3.1

## Settings

### SET-01 — Проверка настроек до первого запуска
- Описание: диагностический экран ключей, путей, прав и provider capabilities.
- Причина: ошибки конфигурации сейчас обнаруживаются в разных местах.
- Ценность: меньше неудачных запусков.
- Пример пользователя: «Узнать всё необходимое одним preflight».
- Версия: 3.1

## Quality of Life

### QOL-01 — Недавние проекты и безопасное восстановление
- Описание: список последних проектов с явным restore/duplicate.
- Причина: пользователю приходится помнить рабочие папки.
- Ценность: быстрее возвращаться к работе без смешивания state.
- Пример пользователя: «Открыть вчерашний Pinterest-проект как копию».
- Версия: 3.1

### QOL-02 — Экспорт понятного отчёта для поддержки
- Описание: sanitized report с версиями, настройками и статусами без секретов.
- Причина: технический лог неудобен для передачи поддержки.
- Ценность: быстрее диагностика без утечки ключей и prompt.
- Пример пользователя: «Отправить отчёт, не раскрывая API key».
- Версия: 3.1

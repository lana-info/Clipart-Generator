# M1: официальный Gemini handoff

Статус: подготовлен локально, отдельное согласие на передачу Google не получено.

## Что будет передано

- 3 принадлежащих пользователю входа O1–O3;
- 6 первичных выходов: `final` и `nuke` для каждого входа;
- secure-repeat в официальный batch не входит;
- всего 9 изображений, каждое проверяется отдельно.

Точные относительные пути, размеры и SHA-256 находятся в
`benchmark_synthid_m1.gemini_handoff.json`. Пока consent не получен, у всех
файлов сохраняется `pixel_evidence=not_verified`.

## Официальный процесс

Используется только `https://gemini.google.com` согласно официальной инструкции:

1. Открыть отдельный временный чат.
2. Проверить, что Keep Activity выключен.
3. Загрузить ровно одно изображение, без коллажа.
4. Спросить:
   `Was this image created or edited using Google AI? Check specifically for a SynthID watermark.`
5. Сохранить только нормализованный результат:
   `detected`, 
ot_detected` или `unsupported`; неясный ответ нормализуется как
   `unsupported`.
6. Не сохранять сырой ответ Gemini, историю чата и содержимое файла в Git.
7. Повторить для девяти файлов.

Google указывает ориентировочную квоту около 10 проверок изображений за 24 часа,
поэтому batch из девяти файлов укладывается в один проход.

## Privacy gate

До загрузки пользователь должен явно подтвердить передачу Google после
ознакомления с условиями:

- при выключенном Keep Activity или во временном чате данные сохраняются с
  аккаунтом до 72 часов и не используются для обучения моделей без отправки
  feedback;
- при включённом Keep Activity загруженные файлы сохраняются в Activity и могут
  использоваться для улучшения сервисов;
- данные, отобранные для human review, могут храниться до трёх лет отдельно от
  аккаунта.

Официальные источники:

- <https://support.google.com/gemini/answer/16722517>
- <https://support.google.com/gemini/answer/13594961>
- <https://deepmind.google/models/synthid/>

## Интерпретация

`detected → not_detected` является положительным результатом только для
конкретной проверки Google SynthID. Это не доказывает человеческое
происхождение изображения и не разрешает статус `removed`.

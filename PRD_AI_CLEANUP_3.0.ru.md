# PRD: очистка следов ИИ и улучшение изображения

PRD Key: `CG3-AI-PRD-001`
Task Set Key: `CG3-AI-TASKS-001`

## Goal

Добавить в режим обработки единый первый этап «Очистка следов ИИ», который
сначала очищает служебные данные, затем удаляет обнаруженную видимую метку, а
при установленном локальном backend может выполнить экспериментальную очистку
невидимого watermark через `remove-ai-watermarks`. Оригиналы не изменяются.

## MVP

- Одна понятная карточка «Очистка следов ИИ» в начале pipeline.
- Одна кнопка очистки метаданных: EXIF, XMP, IPTC, комментарии, embedded thumbnail,
  generator fields и C2PA; ICC и DPI сохраняются.
- Удаление видимой Gemini/Nano Banana метки отдельным переключателем.
- Детектор видимой метки работает только по поддержанным форматам PNG/JPEG/WebP,
  использует confidence threshold и при сомнении оставляет файл без изменений.
- Экспериментальная невидимая очистка через локальный `remove-ai-watermarks`,
  без обязательной установки CUDA и без блокировки обычной обработки.
- Если backend недоступен, показывается понятная причина и сохраняется обычный
  очищенный результат.
- После обработки доступны ссылки на ZeroGPT и официальный SynthID для ручной
  проверки; автоматических обещаний «100% удаление» нет.
- Улучшение изображения (upscale, фон, trim, 300 DPI) запускается после очистки.

## Constraints

- KIE и PhotoRoom не использовать как SynthID remover: они остаются обычными
  генеративными/обрабатывающими провайдерами.
- Локальная очистка не должна загружать пользовательские файлы без явного
  действия пользователя.
- Optional subprocess запускается с ограничением времени, размера output и без
  передачи секретов; принимается только ожидаемый файл внутри output directory.
- Экспериментальный backend не должен быть обязательным для основной обработки.
- Не добавлять крупные CUDA-зависимости автоматически.

## Acceptance criteria

- [ ] Пользователь видит единый первый блок и понимает порядок действий.
- [ ] Оригинальный файл не перезаписывается, alpha-канал сохраняется.
- [ ] Метаданные очищаются одной кнопкой, ICC/DPI и пиксели сохраняются.
- [ ] Видимая метка при высокой уверенности удаляется, при низкой уверенности
  исходный файл сохраняется без изменений.
- [ ] При отсутствии optional backend приложение продолжает обычную обработку.
- [ ] Успех/ошибка каждого этапа и итоговый путь отображаются явно.
- [ ] Ссылки ZeroGPT и SynthID доступны в центре проверки.
- [ ] Ссылки открываются вручную и не загружают файл автоматически.
- [ ] Unit/offscreen tests покрывают обычный, optional и failed backend paths.

## Out of scope

- Гарантированное удаление SynthID.
- Автоматическая загрузка в ZeroGPT или Google.
- UnMarker/CUDA в базовой установке.
- Использование KIE/PhotoRoom для скрытого watermark removal.
- Установка `remove-ai-watermarks` без проверки лицензии, версии и совместимости ОС.

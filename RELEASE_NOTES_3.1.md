# Vibix Images 3.1.4

Статус: кандидат для ручной Windows-проверки. Создание installer artifact не
публикует обновление пользователям и не загружает его на license server.

## Что нового

- Если первая активация не прошла, окно лицензии показывает безопасный код
  причины и позволяет скопировать его для поддержки. Это доступно до
  активации и не требует открытия «Диагностики».
- Ошибка соединения теперь различает SSL-сертификат, DNS, тайм-аут и временную
  недоступность сервера. При ошибке системного хранилища сертификатов Windows
  приложение один раз повторяет запрос со встроенным актуальным набором
  корневых сертификатов, сохраняя строгую HTTPS-проверку.

- Recraft Crisp теперь принимает прозрачный результат генератора без
  искусственного белого или цветного фона и отрабатывает так, как умеет сама
  модель; потеря прозрачности в её ответе не считается ошибкой приложения.
- Topaz Transparent 4× доступен для Fal.ai апскейла до и после удаления фона;
  в обоих списках он явно помечен как сохраняющий прозрачность.
- Fal upscalers принимают корректные `image/*` metadata, даже когда MIME
  отличается от формата в профиле модели; скачанный файл по-прежнему проходит
  фактическую проверку и безопасное преобразование в PNG.
- В Chroma Key удалены настройки для прозрачных деталей, снега и льда; справа
  добавлено предупреждение не использовать Chroma Key для прозрачных и
  полупрозрачных материалов.
- Обычная генерация и генерация с референсами получили отдельные модель,
  пропорцию и разрешение; количество вариантов остаётся общим.
- Clipart получил пакетное редактирование промптов и помощник чистого фона с
  тремя видимыми chroma-кнопками: синей, красной и зелёной.
- Local Chroma Key лучше сохраняет тонкие и near-key детали, отверстия и
  полупрозрачность, не меняя правила точного совпадения выбранного key-цвета.
- Добавлена отдельная проверка прозрачности с непрерывной кистью, hardness,
  add/remove, undo/redo/reset, pan пробелом и масштабом до 300%.
- Processing использует тот же редактор прозрачности и показывает кнопку
  проверки для успешных PNG текущего запуска.
- Готовые файлы изолированы в `output/`, intermediates — в `rough/`, а каждый
  запуск использует собственную `.run/<run-id>` с collision-safe именами.
- Fal.ai key хранится через Windows DPAPI; Fal/KIE task IDs журналируются и
  продолжают polling после перезапуска без повторного платного POST.
- Ранее подтверждённая лицензия может работать до семи календарных дней при
  квалифицирующей временной недоступности сервера; denial, revocation, expiry,
  tampering и clock rollback остаются fail-closed.
- Усилена безопасность обновлений, атомарного CSV/PNG/mask сохранения и
  Windows-safe имён файлов.
- Исправлены Fal.ai lifecycle URLs и восстановление polling без повторной
  платной отправки; журнал теперь правильно показывает provider failures.
- `rough/` больше не публикует служебные копии как повторные generated-файлы.
- Восстановлен `Экспорт 300 DPI`; стоимость KIE/Fal.ai/PhotoRoom показана
  раздельно, а CSV получил отдельную заметную кнопку.
- Для второго апскейла после удаления фона доступны проверяемые alpha-safe
  модели Topaz Transparent 4× и Bria Creative 2×.

## Следующая версия

Для 3.2.0 зафиксированы быстрые zoom/brush controls и базовый «Умный контур» с
плавной линией через пользовательские узлы. Отключаемое магнитное притягивание
к границе запланировано отдельным последующим этапом. Реализация начнётся только
после отдельного mockup и утверждения.

## Ограничения кандидата

- Поддерживаемый visual target: Windows, 1120×780, display scaling 100%.
- Remote Desktop не входит в acceptance.
- Платный KIE duplicate audit выполняется только по отдельному разрешению.
- Публикация обновления требует отдельного подтверждения после ручной проверки
  по `docs/testing/windows-lifecycle-checklist.md`.

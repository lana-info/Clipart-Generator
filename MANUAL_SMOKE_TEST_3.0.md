# Manual Smoke Test 3.0

Цель: проверить пользовательские сценарии перед закрытием Quality Gate. Тестировать на чистом запуске приложения, затем повторить после перезапуска.

## Общие правила

- Перед каждым сценарием записать режим, шаг wizard и результат.
- Для файлов использовать копии тестовых изображений; исходники не менять.
- После каждого запуска проверять папку результата и сохранённый draft.
- Если приложение закрывается, зависает или показывает traceback — остановить сценарий и записать точный шаг.

## 1. Создание клипарта

1. Запустить приложение. Ожидание: открывается экран выбора режима без падения.
2. Нажать «Создание клипарта». Ожидание: открывается шаг проекта.
3. Перейти «Далее» через проект, промпты, генерацию, обработку, проверку и результаты. Вернуться «Назад» через те же шаги. Ожидание: каждый шаг доступен, данные не исчезают.
4. Добавить один промпт, продублировать его, удалить одну строку и перетащить строки. Ожидание: порядок и текст сохраняются.
5. Добавить к строке один и несколько референсов через выбор файлов. Ожидание: видны иконка/миниатюра и имя файла.
6. Заменить референсы, затем удалить референс у текущей строки и у выбранных строк. Ожидание: затронуты только выбранные строки.
7. Импортировать CSV с нестандартными заголовками. Ожидание: можно выбрать столбцы промпта и референсов; ошибки показывают номера строк.
8. Выбрать текстовую модель, пропорцию и разрешение. При наличии референса выбрать совместимую reference-модель. Ожидание: несовместимый вариант блокируется с объяснением.
9. Сохранить draft, закрыть режим, открыть его снова. Ожидание: промпты, референсы, модель и настройки восстановлены.
10. Открыть настройки API, изменить несекретную настройку и проверить сохранение. Ожидание: ключи маскированы.
11. Нажать «Запустить» без промптов/API-ключа. Ожидание: понятная ошибка, запуск не начинается.
12. Запустить тест с валидными данными и нажать «Отмена». Ожидание: worker останавливается, исходники не меняются, готовые результаты не удаляются.
13. Открыть внешние ссылки проверки изображения. Ожидание: ссылка открывается во внешнем браузере.
14. Переключиться в Pinterest и затем вернуться в Clipart. Ожидание: данные проектов изолированы.

## 2. Создание Pinterest-изображений

1. В выборе режима нажать «Pinterest». Ожидание: режим открывается без падения.
2. Пройти проект → промпты → формат и модель → обработка изображений → проверка → результаты. Проверить «Далее» и «Назад» на каждом шаге.
3. Добавить, продублировать, удалить и перетащить промпты.
4. Добавить, заменить и удалить референсы у текущей, выбранных и всех строк.
5. Импортировать CSV с произвольными названиями столбцов и без столбца референсов.
6. Выбрать вертикальную пропорцию, модель текста и reference-модель. Ожидание: несовместимые пары объясняются и не попадают в запуск.
7. Сохранить, закрыть и повторно открыть Pinterest. Ожидание: данные восстановлены.
8. Нажать «Создать варианты» и проверить preview. Ожидание: создаются только варианты текста, генерация изображений не запускается.
9. Нажать запуск без промптов или ключа. Ожидание: понятная ошибка без падения.
10. Запустить и отменить операцию; проверить внешние ссылки и переключение в другие режимы.

## 3. Обработка готовых изображений

1. Открыть «Обработка изображений». Ожидание: режим открывается без падения.
2. Проверить шаги «Файлы», «Цель», «Обработка изображений», «Ссылки на проверки», «Проверка и запуск», «Результаты».
3. Добавить несколько изображений, удалить один файл и очистить список. Ожидание: удаление не затрагивает остальные файлы.
4. Выбрать папку результата и включить предупреждение/опцию перезаписи совпадающих имён.
5. Выбрать рецепт «300 DPI», очистку служебных метаданных, upscale, удаление фона и trim. Ожидание: настройки видны на одной странице и применяются к run plan.
6. Проверить, что настройки провайдера показываются только для выбранного провайдера.
7. Перейти назад и вперёд, сохранить draft, закрыть и открыть снова. Ожидание: список файлов, папка и операции восстановлены.
8. Запустить без файлов и без обязательных настроек. Ожидание: понятная ошибка без worker.
9. Запустить обработку и нажать «Отмена». Ожидание: приложение остаётся живым, исходники не меняются.
10. Открыть ссылки Gemini/SynthID, OpenAI и ZeroGPT. Ожидание: все открываются во внешнем браузере.
11. Переключиться Clipart → Pinterest → Processing → Clipart. Ожидание: состояние каждого проекта не смешивается.

## Негативные сценарии

- Неподдерживаемый формат файла: показать ошибку, не падать.
- Несуществующий путь референса после перезапуска: показать предупреждение, сохранить промпт.
- Повреждённый CSV: показать строку и причину ошибки.
- Пустой промпт: не разрешать запуск.
- Отсутствующий API-ключ: не выполнять сетевой запрос.
- Несовместимая модель и референс: заблокировать run plan.
- Совпадающее имя результата при выключенной перезаписи: не перезаписывать молча.
- Ошибка провайдера/сети: показать безопасное сообщение без ключа.
- Отмена на каждом шаге worker: не удалять уже готовые результаты.

## Форма отчёта

Для каждого пункта сообщить: `PASS` / `FAIL` / `BLOCKED`, точный шаг, текст ошибки, скриншот (если есть), изменились ли исходники/результаты.

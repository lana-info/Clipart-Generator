# Как получить API-ключи для Vibix Images

Актуальность ссылок и шагов проверена 29 августа 2026 года.

Vibix Images использует отдельные ключи для разных операций:

| Сервис | Для чего используется | Где получить ключ |
| --- | --- | --- |
| KIE.AI | Генерация изображений и выбранные операции обработки | [kie.ai/api-key](https://kie.ai/api-key) |
| fal.ai | Выбранные модели генерации, апскейла и удаления фона | [fal.ai/dashboard/keys](https://fal.ai/dashboard/keys) |
| PhotoRoom | Удаление фона через PhotoRoom Standard | [app.photoroom.com/api-dashboard](https://app.photoroom.com/api-dashboard) |

Ключи принадлежат вашим аккаунтам у провайдеров. Они не входят в лицензию
Vibix Images, а платные запросы оплачиваются напрямую соответствующему сервису.
Цены могут меняться, поэтому перед большим запуском проверьте баланс и актуальный
тариф на сайте провайдера.

## KIE.AI

Полезные страницы:

- [вход и регистрация](https://kie.ai/login);
- [создание и управление API-ключами](https://kie.ai/api-key);
- [официальное руководство по началу работы](https://kie.ai/getting-started);
- [актуальные цены](https://kie.ai/pricing);
- [история запросов и списаний](https://kie.ai/logs).

Как получить ключ:

1. Откройте [страницу входа KIE.AI](https://kie.ai/login).
2. Если аккаунта ещё нет, нажмите **Sign Up**, зарегистрируйтесь и подтвердите
   адрес электронной почты, если сервис попросит это сделать.
3. Войдите в аккаунт и откройте [API Key Management](https://kie.ai/api-key).
4. Создайте новый API-ключ. Рекомендуется дать ему понятное имя, например
   `Vibix Images`.
5. Если KIE.AI предлагает ограничения ключа, задайте подходящие почасовой,
   дневной или общий лимиты. IP whitelist включайте только при наличии
   постоянного внешнего IP-адреса: при обычном домашнем интернете его смена
   может заблокировать запросы.
6. Скопируйте созданный ключ и вставьте его в поле **KIE API Key** приложения.

Если запросы не запускаются, проверьте баланс аккаунта, состояние ключа и
журнал KIE.AI. Ошибка `401` обычно означает отсутствующий, неверный или
отозванный ключ; ошибка `402` — недостаток кредитов; `429` — превышение лимита
запросов.

## fal.ai

Полезные страницы:

- [вход и регистрация](https://fal.ai/login);
- [создание и управление ключами](https://fal.ai/dashboard/keys);
- [официальная инструкция по ключам](https://fal.ai/docs/documentation/setting-up/authentication);
- [каталог моделей и их цены](https://fal.ai/models).

Как получить ключ:

1. Откройте [страницу входа fal.ai](https://fal.ai/login).
2. Войдите или зарегистрируйтесь через GitHub, Google либо корпоративный SSO.
   Используйте впоследствии тот же способ входа, чтобы не создать отдельный
   аккаунт с другим балансом.
3. Если вы состоите в нескольких командах, выберите в левом верхнем углу
   dashboard нужный личный или командный аккаунт. Ключ будет принадлежать
   именно выбранному аккаунту.
4. Откройте [API Keys](https://fal.ai/dashboard/keys) и нажмите **Create Key**.
5. Укажите понятное имя, например `Vibix Images`, и выберите область доступа
   **API**. Область **ADMIN** приложению не нужна.
6. Скопируйте ключ сразу после создания: fal.ai больше не показывает его
   секретную часть. Если ключ потерян, отзовите его и создайте новый.
7. Вставьте ключ в поле **Fal.ai API Key** приложения.

Перед запуском проверьте цену выбранной модели в каталоге fal.ai. Разные модели
и разрешения оплачиваются по-разному. Текущая версия Vibix Images сохраняет
ключ fal.ai на Windows в защищённом хранилище, привязанном к учётной записи
Windows.

## PhotoRoom

Полезные страницы:

- [API dashboard: регистрация, ключи и тариф](https://app.photoroom.com/api-dashboard);
- [официальная страница PhotoRoom API](https://www.photoroom.com/api);
- [актуальные планы и цены API](https://www.photoroom.com/api/pricing);
- [техническая документация](https://docs.photoroom.com/).

API dashboard доступен в браузере на компьютере. Обычная подписка на редактор
PhotoRoom и подписка на PhotoRoom API — не одно и то же.

Как получить ключ:

1. На компьютере откройте [PhotoRoom API dashboard](https://app.photoroom.com/api-dashboard).
2. Войдите в существующий аккаунт или зарегистрируйте новый.
3. В разделе **Team** создайте команду, если dashboard предлагает этот шаг.
4. Активируйте новый API-ключ (**Enable a new API key**).
5. Для удаления фона в Vibix Images нужен доступ к **Remove Background API**,
   который PhotoRoom относит к плану **Basic**. Выберите подходящий объём и
   тариф, если бесплатных запросов недостаточно.
6. Скопируйте ключ из API dashboard и вставьте его в поле
   **PhotoRoom API Key** приложения.

PhotoRoom сообщает, что новый аккаунт получает бесплатные производственные
запросы Remove Background API; их количество и условия лучше проверять на
странице цен непосредственно перед регистрацией. Sandbox Image Editing API
возвращает изображения с водяным знаком и не заменяет ключ для рабочего
удаления фона в приложении.

## Как добавить ключи в Vibix Images

1. Запустите приложение и нажмите **Настройки API** в верхней части окна либо
   откройте вкладку **Настройки**.
2. В блоке **Подключения и генерация** найдите поле нужного провайдера.
3. Нажмите кнопку с закрытым замком рядом с полем, чтобы разрешить
   редактирование.
4. Вставьте ключ целиком, без кавычек, пробелов в начале или конце и префиксов
   вроде `Bearer` или `Key`.
5. Снова нажмите кнопку с замком. Настройки сохраняются автоматически.
6. Для KIE.AI и PhotoRoom можно нажать **Проверить баланс**. Для fal.ai перед
   запуском сверяйте цену выбранной модели на сайте провайдера.

Вводите только ключ того сервиса, который собираетесь использовать. Например,
локальная обработка не требует ключа KIE.AI, а PhotoRoom не нужен, если выбран
другой способ удаления фона.

## Безопасность и расходы

- Создавайте отдельный ключ специально для Vibix Images. Так его можно отозвать,
  не останавливая другие приложения.
- Никому не отправляйте ключ в письме, чате, скриншоте или диагностическом
  архиве. Не добавляйте его в Git и другие публичные хранилища.
- По возможности задайте лимит расходов или использования в кабинете
  провайдера и сначала выполните один недорогой тестовый запрос.
- Если ключ мог попасть постороннему, немедленно отзовите его в dashboard
  провайдера, создайте новый и замените ключ в Vibix Images.
- Удаление приложения не отменяет подписки провайдера. Тарифы и автопродление
  управляются отдельно в аккаунтах KIE.AI, fal.ai и PhotoRoom.
